# Spearman V2 artwork

Generated with the built-in `image_gen` tool on 2026-10-21. Identity references: `modelทวน/ทวนอธรรม.png` and `modelทวน/ทวนธรรมมะ.png`. Final transparent RGBA sources are `adharma-source.png` and `dharma-source.png` (1402×1122 each). The dharma atlas is a palette/identity edit of the adharma atlas to preserve poses and registration. Inventory-only `*-weapon-icon.png` files retain the original reference spear cutouts; these never render over the character.

The game uses deterministic atlas packing (`tools/build-spearman.js`) and canvas effects, equipment fittings and level ornaments. Rebuild with `npm run spearman`. Changing a source requires reviewing cell boundaries, feet, hands and weapon tips before packing.
