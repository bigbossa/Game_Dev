## ไฟล์และวิธีสร้าง

- `map-art/ice-v2/`: ต้นฉบับภาพและ `PROMPTS.md` สร้างด้วย **built-in image_gen**; `snow-source.png` เป็นวัสดุหิมะ
- `monster-art/ice-v2/`: ต้นฉบับทั้ง 7 ชนิด, `SPRITES.json` เก็บ prompt และ mapping, `PROMPTS.md` บันทึกการแก้ atlas บอสที่เคยชิดกัน
- `node tools/build-ice-art.cjs`: แยกวัตถุตาม alpha จริงและแพ็กเป็น `public/assets/ice-v2/`
- `node tools/build-ice-monsters.cjs`: แพ็กสไปรต์ลง `public/assets/monsters/*-v2.png` และอัปเดตเฉพาะรายการด่านน้ำแข็งใน `index.json`
- `public/js/ice-art.js`: โหลดภาพ สร้างภาพย่อย และวาดพื้นตามพิกัดโลกใน chunk cache ใช้มาสก์หิมะเก็บตามแผนที่ ไม่สร้างรายละเอียดใหม่ทุกเฟรม
- `world-art.js`, `main.js`, `hunting-review.js` และหน้า HTML เชื่อมชุดใหม่พร้อมเวอร์ชัน manifest `ice-palace-v2`
