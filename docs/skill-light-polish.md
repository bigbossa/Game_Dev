# แสงสกิลและจังหวะโจมตี — 26 ตุลาคม 2026

เพิ่มแสงออกท่าให้สกิลทั้ง 7 อาชีพ และเปลี่ยนภาพกระแทกเมื่อโจมตีโดนเป็นลายประจำอาชีพ ใช้ร่วมกับท่าทาง เส้นทางอาวุธ วิชาระดับสูง และวงเตือนเดิม ทั้งธรรมะและอธรรมมีชุดสีของตนเอง

| อาชีพ | ภาพและการเคลื่อนไหว |
| --- | --- |
| ดาบคู่ | คมจันทร์ไขว้ หมุนแยกชั้น และเงาคมที่ขยายออก |
| ทวน | หัวทวนแสงและเส้นพลังขนานพุ่งตามแนวโจมตี |
| ธนู | หัวศรกับแพขนนก และเส้นแสงตามวิถียิง |
| นักพรต | กลีบบัว ตราหยินหยาง และลายหมุนสวนกัน สีหยก/ม่วงแดงตามฝ่าย |
| นักรบแนวหน้า | โล่เหลี่ยมซ้อนกรอบ ประกายทองแตกเป็นพัดลงพื้น |
| เทวทัณฑ์ | ดาบตรงกลาง ปีกแสงสองข้าง และเส้นประกายแนวดิ่ง |
| นักสู้หมัดปราณ | กำปั้นปราณ บีบ–ขยายตอนกระแทก และเงาหมัดซ้อนชั้น |

แสงออกท่าติดตามตำแหน่งภาพตัวละคร รวมการพุ่งและยกตัวจากท่าสกิล เพิ่มขนาดตามขั้นที่เรียน สกิลพื้นฐานใช้ขนาดเล็กและเวลาสั้น ส่วนภาพกระแทกเกิดผ่าน `FX.hit` เมื่อได้รับผลโจมตีจากเซิร์ฟเวอร์ คริติคอลขยายแสงและค้างนานขึ้นเล็กน้อย การเปลี่ยนนี้ไม่แก้ดาเมจ จำนวนฮิต ระยะ MP หรือคูลดาวน์

## คุมภาระเครื่อง

- วาดลาย แสงฟุ้ง และเส้นประกายลงภาพขนาดเล็กแล้วใช้ซ้ำ แคชมีจำนวนตายตัว 14 ชุด (7 อาชีพ × 2 ฝ่าย) รวมประมาณ 6.6 MiB ของข้อมูล RGBA ก่อนค่าใช้จ่ายภายในเบราว์เซอร์
- สวยเต็มที่ใช้แสงฟุ้ง เงาซ้อน และเส้นประกาย จำกัดส่วนเสริมพร้อมกัน 48 รายการ
- อัตโนมัติจำกัด 24 รายการ เมื่อเครื่องลดรายละเอียดจะเหลือ 16 รายการ และใช้ภาพลายหลักเพียงครั้งเดียวต่อเอฟเฟกต์ต่อเฟรม
- เน้นลื่นจำกัด 12 รายการ ใช้ภาพลายหลักที่ยังแยกอาชีพ/ฝ่ายได้
- ข้ามภาพที่อยู่นอกจอ ไม่มีตัวจับเวลาสร้างประกายซ้ำระหว่างวาด ไม่มีการอ่านพิกเซลใน renderer จริง และไม่ขับรายการวงเตือนเดิมออกจากคิว
- ล้างส่วนเสริมเมื่อถูกยกเลิก สตัน ตรึง ตาย หรือย้ายแผนที่ ตรวจ token ของการร่ายเพื่อไม่ให้คำสั่งยกเลิกเก่าลบแสงของท่าถัดไป

## ตรวจสอบ

`node tools/check-skill-polish.cjs http://127.0.0.1:3922 9362` ใช้ preview แบบไม่มีบัญชี ทดสอบ 79 สกิลในข้อมูลปัจจุบัน รวม 474 การออกท่า ครบ 3 โหมดและ 2 ฝ่าย ตรวจความต่างของลาย 14 แบบ การยกเลิก การซ่อนเอฟเฟกต์หลังตาย/ย้ายแผนที่/อยู่นอกจอ การคืนสถานะ Canvas เพดานจำนวน และการรักษาวงเตือน รวมถึงเส้นทางรับเหตุการณ์จริงของทั้ง 7 อาชีพ

เครื่องมือเดียวกันตรวจหน้าแพตช์โน้ตบนจอคอมและมือถือจำลอง ทั้งการเปิดอ่าน รายการล่าสุด การจำว่าอ่านแล้ว ขนาดหน้าต่าง และปุ่มในเมนูมือถือ ภาพและรายงานอยู่ที่ `artifacts/skill-polish/` (ไม่เข้า Git)

เพิ่ม `--skill-stress` ใน `tools/benchmark-render.cjs` เพื่อวัดฉากสังเคราะห์มอนสเตอร์ 48 ตัว ผู้เล่น 7 อาชีพ และภาพโจมตีโดน 21 ครั้งทุก 250 ms ร่วมกับประกายชุดทดสอบเดิม ผลบนเครื่องพัฒนาที่ 1280×900 DPR 1 โหมดอัตโนมัติ: ก่อน 29.2 FPS / P95 66.6 ms หลังปรับเพดานและเส้นทางวาดแบบเบา 39.3 FPS / P95 33.4 ms (`skill-polish-before.json`, `skill-polish-final.json`) ตัวเลขนี้ไม่ใช่ฉากเดียวกับรายงานเพิ่มความลื่นรอบก่อน และไม่ใช่ผลรับรองทุกเครื่อง

จอมือถือจำลอง 390×844 DPR 3 ในฉากเดียวกันได้ 21.0 → 45.0 FPS และ P95 66.6 → 33.4 ms แต่ตัวปรับอัตโนมัติจบรอบก่อนที่สเกล 80% และรอบหลังที่ 70% ผลจึงรวมการลดความละเอียดเพิ่มด้วย ไม่ใช่การเทียบภาพความละเอียดเท่ากัน และยังไม่ได้ทดสอบบนฮาร์ดแวร์โทรศัพท์จริง (`skill-polish-mobile-before.json`, `skill-polish-mobile-final.json`)

ไฟล์หลัก: `public/js/skill-polish.js`, จุดเชื่อมใน `main.js` และ `skill-fx.js` ส่วนข่าวผู้เล่นอยู่ที่ `public/patch-notes.json`
