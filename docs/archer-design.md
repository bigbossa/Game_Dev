# นักธนู V2

โมเดลเอลฟ์ใหม่ทั้งตัว ใช้ภาพต้นแบบโปร่งใสจาก image_gen แยกชุดออกจากอาวุธ โดยใช้วิธีแต่งวัสดุบนรอยผ้าแบบเดียวกับดาบคู่

- Lv.1–49: ผมบ๊อบสั้น; Lv.50–99: หางม้าประบ่า; Lv.100–130: หางม้ายาวถึงน่อง
- ธรรมะ: ผมน้ำตาลไปสู่เงินงาช้าง ชุดเขียวเข้ม ลายเงินและทอง
- อธรรม: ผมม่วงเข้มไปสู่ดำแดง ชุดสีราตรี ลายเงินอมม่วงและทองแดง
- ชุด 9 ขั้นและชุดเริ่มต้นเปลี่ยนวัสดุแยกตามช่อง: ตัว ขา แขน ไหล่ ลายระดับสูงขยายเฉพาะบนพื้นผ้าที่วาดไว้ ไม่เพิ่มชิ้นเกราะลอย
- Lv.120 ใช้ลายเงินหยก/อเมทิสต์; Lv.130 ใช้ลายทอง/ทองแดงแดง
- ยืนและเดินใช้ชุดภาพต้นแบบเดียวกัน เท้าตรงจุดอ้างอิงเดียวกัน ท่ายิงแยกเตรียม ง้าง และปล่อยสายธนู โดยสองเฟรมท้ายใช้ท่าร่างกายเดียวกัน
- ทิศซ้ายใช้ภาพสะท้อนจากทิศขวา รวม 8 ทิศ ขนาดเฟรม 240×180 มีขอบเผื่ออาวุธ
- ธนูแสดงหลังมือจากจุดจับที่ระบุในแต่ละท่า และคงวัสดุ/ลายอาวุธตามขั้นเดิม
- ปีกเอลฟ์ มงกุฎและจุดแสงอุปกรณ์ใช้จุดอ้างอิงโมเดลใหม่ รูปโปรไฟล์และเลือกฝ่ายใช้โมเดลใหม่ด้วย

แหล่งภาพ: `class-art/archer-v2/` พร้อม `PROMPTS.md` ส่วนภาพใช้งานอยู่ที่ `public/assets/archer-v2/`
สร้างใหม่ด้วย `npm run archer`; ตัวสร้างภาพเดิมเก็บไว้ใน `npm run archer:legacy`

ตรวจด้วย `node tools/check-archer-v2.cjs http://localhost:3901 9334` เมื่อเปิดเซิร์ฟเวอร์และเบราว์เซอร์ทดสอบแยกไว้
ตรวจ alpha ของชุดเทียบภาพต้นฉบับทุกพิกเซล สีผิว ตำแหน่งจุดแสง วัสดุแต่ละขั้น และ cache พร้อมสร้างภาพตัวอย่างทั้งสองฝ่ายครบ 8 ทิศ

ตัวอย่างหมุนและเล่นท่า: `artifacts/archer-v2-preview.html`
