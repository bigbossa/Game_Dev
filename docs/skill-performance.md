# แอนิเมชันและเอฟเฟกต์สกิลทุกอาชีพ — 23 ตุลาคม 2026

> อัปเดต: ดาบคู่ ทวน ธนู และนักพรตใช้ [สกิลชุดใหม่ 44 ท่า](skill-redesign.md) แทนการเสริมท่ารวมของรุ่นแรกด้านล่าง ดาบโล่ยังใช้ชุดท่าเดิมของเอกสารนี้ กติกาการต่อสู้ทวนและขั้นสกิลยังใช้ต่อ

ครอบคลุม 55 สกิลของ 5 อาชีพ ทั้งธรรมะและอธรรม ใช้ท่าระดับ 120–130 เป็นแนวทางแบ่งการเคลื่อนไหวเป็นเตรียมท่า → ออกแรง/ปล่อยพลัง → เก็บท่า โดยคงภาพตัวละครและอาวุธจาก atlas เดิม แล้วเพิ่มการหมุน หันตัว ย่อ กระโดด ลอยตัว และแรงถอยด้วยตัว renderer จริง

| อาชีพ | ท่าทางและภาพประกอบ |
| --- | --- |
| ดาบคู่ | ถ่ายน้ำหนักก่อนฟัน คมคู่สลับข้าง หมุนตัว ก้าวพุ่ง ภาพเงาตามท่า คอมโบพันคมตามจำนวนครั้งของสกิล |
| นักพรต | ยกมือร่าย/ปัดอาวุธ ลอยตัวตามความแรงของวิชา ยันต์หมุนและวงตรา ขยับกลับลงพื้นหลังร่าย |
| ธนู | ง้างคันธนู ปล่อยสาย แรงถอย องศาเอนตัว พลิกหลบ ท่ายิงจากกลางอากาศ พร้อมขนนก/เส้นสายธนู |
| ทวน | แทงเปิด → พลิก/หมุน → ปิดคอมโบ ใช้ตารางเวลาเดียวกับเซิร์ฟเวอร์ พร้อมผลกระแทกที่เซิร์ฟเวอร์ยืนยัน |

## การเพิ่มรายละเอียดตามขั้น

เซิร์ฟเวอร์ส่ง `sl` (แต้มสกิล 1–12) พร้อม `r` (ขั้นวิวัฒนาการที่เรียนจริง) ในเหตุการณ์สกิล ทั้งผู้เล่นเองและคนรอบข้างจึงเห็นขั้นเดียวกัน

- สกิลทั่วไป: ระดับรายละเอียด `min(3, r + floor((sl - 1) / 4))` เพิ่มที่แต้ม 5 และ 9 รวมกับขั้นวิวัฒนาการ
- เริ่มต้น: ลายพลังเล็ก จังหวะร่างกายชัด และสีตามอาชีพ/ฝ่าย
- ขั้นสูงขึ้น: เพิ่มเส้นพลัง ยันต์/ขนนก น้ำหนักท่า และภาพเงาไม่เกิน 2 ภาพ
- สกิล 120 และ 130: ระดับรายละเอียดเฉพาะ 4 และ 5 ใช้ท่าเคลื่อนที่และผลระเบิดของระบบ Ascended เดิม เสริมรายละเอียดรอบผู้ร่าย
- ออร่าประจำตัวและชุดตามเลเวลยังทำงานร่วมกับรายละเอียดตามแต้มสกิล

การปรับอาชีพอื่นเป็นภาพและท่าทาง ไม่เปลี่ยนจำนวนฮิต ดาเมจ ระยะ MP หรือคูลดาวน์ของสกิล วงประดับใต้ผู้ร่ายเป็นลายตกแต่ง ไม่ใช่ขอบเขตดาเมจ

สามท่าหมู่ยังต้องล็อกเป้าหมายหลัก จึงใช้เป็นสกิลกวาดรอบศัตรูได้ แต่ไม่ใช่การโจมตีพื้นเปล่า ผลรวมตัวคูณโจมตีและน้ำหนักหักเกราะของเป้าหมายหลักคงงบเดิม โดยแบ่งน้ำหนักไปตามจังหวะใหม่ เอฟเฟกต์ฟื้น MP และโอกาสสายฟ้าจากอุปกรณ์ถ่วงตามน้ำหนักฮิต; ศัตรูเสริมไม่เพิ่มงบเอฟเฟกต์อุปกรณ์นั้น

เป้าหมายหลักออกนอกระยะ ตาย เปลี่ยนแมพ ผู้ร่ายติด stun/root หรือล็อกเอาต์ จะยุติคอมโบและไม่กลับมาโจมตีต่ออัตโนมัติเมื่อเป้ากลับมา ศัตรูเสริมต้องผ่านกติกา PvP/ปาร์ตี้/พื้นที่ปลอดภัยและไม่มีกำแพงกั้น เลือดไหล ลดเกราะ และสถานะเฉพาะเป้าหมายไม่แพร่ตามดาเมจหมู่

## เส้นทางท่าสกิลตามขั้น (`skill-choreo.js`)

สกิลปกติทุกอาชีพ รวมดาบโล่ใช้ "เส้นทางร่าง" แบบเดียวกับวิชา Lv.120/130: ตัวละครเคลื่อนที่จริง (พุ่ง ก้าวไขว้ หมุน เหิน ดิ่ง) แล้วกลับจุดเดิม เซิร์ฟเวอร์ไม่ย้ายตำแหน่งจริง และไม่เปลี่ยนดาเมจ ระยะ หรือคูลดาวน์

| ขั้น | ที่มา | เส้นทาง | เวลาภาพขั้นต่ำ |
| --- | --- | --- | --- |
| 0 | แต้ม 1–4 | ย่อ → พุ่ง/ง้าง → ฟัน → ถอย | 420 ms |
| 1 | แต้ม 5+ หรือวิวัฒนาการ | + ฟันสองจังหวะสลับข้าง | 560 ms |
| 2 | | + หมุนตัวกลางคอมโบ / ตีลังกาหลัง (ธนู) | 700 ms |
| 3 | แต้ม 9+ หรือสกิล Lv.30+ ที่ฝึกแล้ว | + เหินสูง ~100–180 px แล้วดิ่ง/ทุบ หรือตีลังกาข้ามทวน | 880 ms |
| 4–5 | ดาบโล่ Lv.120 / Lv.130 | คอมโบ 4 ฟัน หมุน เหินสูงสุด 200 px แล้วทุบพื้น | 1150 / 1450 ms |

- ดาบคู่ ทวน ดาบโล่ พุ่งเข้าหาเป้าหมายจริง (ระยะ 50–190 px), ธนูถอยหลังและยิงกลางอากาศ, นักพรตลอยตัวร่ายยันต์
- สกิลโจมตีพื้นฐาน (คูลดาวน์ ~1 วินาที) ใช้เส้นทางสั้นและเวลาเดิม กดรัวแล้วไม่กระตุก
- สกิลที่เซิร์ฟเวอร์ย้ายตัวอยู่แล้ว (skyfall, shadowstep, twindragon, rollshot) และบัฟ/การ์ดแสดงท่าอยู่กับที่
- ท่าย่อยของแต่ละสกิลจาก SkillDesigns ซ้อนบนเส้นทาง ทำให้สกิลอาชีพเดียวกันยังเคลื่อนต่างกัน; จังหวะฟันที่เซิร์ฟเวอร์กำหนดหันเข้าเป้าเสมอ
- เดินออกหลังจังหวะฟันสุดท้ายจะจบท่าทันที; การหมุนเกิน ~30° หมุนรอบเอว (แก้หัวจมพื้นของ rollshot)
- วิชา ritual Lv.120/130 ของสี่อาชีพไม่ถูกแก้

เอฟเฟกต์ตามเส้นทาง (อ้างอิงดาบคู่ 120/130; ไม่วาดทับตัวละคร)

- แถบแสงตามเส้นทางด้านหลังตัว พร้อมอาวุธแสงประจำอาชีพนำหน้า
- ขั้น 1+: ร่างเงาที่ตำแหน่งที่ร่างผ่านไปแล้วเท่านั้น (ไม่ซ้อนกับตัว), สูงสุด 3 ร่าง
- เส้นฟันแสงหน้าตัวทุกจังหวะฟัน; ขั้น 2+ ประกายดาว; ขั้น 3+ ฟันกากบาท
- พื้น: วงแรงกระแทกตอนลง/ทุบ, ขั้น 2+ รอยเส้นทางบนพื้น, ขั้น 3+ รอยแตกรอบวง

งบภาพ: ไม่เกิน 48 โหนด ภายในเพดาน 96 ของ SkillPerformance; ร่างเงาทั้งตัวรวมไม่เกิน 8 ครั้งต่อเฟรม; ไม่สร้าง timer

ตรวจ: `node tools/check-skill-performance.cjs <server> <cdp-port>` (ทุกสกิลปกติมีเส้นทาง/เอฟเฟกต์, ritual ไม่ถูกเพิ่ม, แต้มสกิล 12 มีจังหวะมากกว่าแต้ม 1)
