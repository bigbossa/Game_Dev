## มอนสเตอร์

- ป่ามาร: ต้นไม้อสูรพันราก, แมงมุมม่วงพิษร้าย, ภูตจิ้งจอกไฟผี, นักพรตมารเงา, หมีดำบ้าคลั่ง, ยักษ์ตะไคร่ป่ามาร และพฤกษามารพันปี
- จวนร้าง: ทหารวิญญาณเฝ้าจวน, งูหลามหินผา, รูปปั้นทวารบาล, วิญญาณนางรำคืนจันทร์, องครักษ์ไร้เศียร, อีกาวิญญาณมรณะ และแม่ทัพผีพันศพ
- ประตูเทพยุทธ์: พยัคฆ์ขาวพิทักษ์, กระเรียนเพลิงสวรรค์, ภิกษุพิทักษ์ทวาร, ยักษ์สำริดเทวาลัย, พญานาคหยกมรกต, สิงโตทองเทวาลัย และราชันอสูรสงคราม
- หุบเขาเพลิง: แมงป่องลาวาเดือด, พยัคฆ์อัคคี, ยักษ์หินหลอมเหลว, หงส์ไฟฟีนิกซ์, มังกรเพลิงเยาว์, ขุนพลอัคคีนรก และมังกรอัคคีบรรพกาล

## ไฟล์ต้นฉบับและการสร้าง

สร้างภาพด้วย **built-in image_gen** ตามสกิล imagegen ต้นฉบับเก็บใน workspace และใช้ alpha จริงแยกแต่ละวัตถุ/ท่า โดยไม่ตัดผ่านขอบภาพ:

- `map-art/stages-v2/*-source.png`: ภาพวัตถุของทั้ง 4 ด่าน; `ART.json` เก็บ prompt หลัก, palette, รายชื่อและลำดับวัตถุของแต่ละภาพ
- `monster-art/stages-v2/*-source.png`: ภาพครบ 28 ชนิด; `SPRITES.json` เก็บ prompt หลักและ subject ของแต่ละชนิด รวมลำดับท่าและทิศ
- `node tools/build-stage-art.cjs`: แพ็กวัตถุลง `public/assets/stages-v2/{forest,manor,temple,fire}/`
- `node tools/build-stage-monsters.cjs`: แพ็กภาพ `public/assets/monsters/*-v2.png` และอัปเดตเฉพาะ 28 รายการใน manifest
- `tools/stage-atlas.cjs`: ตรวจเกาะ alpha ขอบภาพ ช่องที่ขาดและท่าที่ติดกันก่อนแพ็ก
- `public/js/stage-art.js`: แคชภาพต้นไม้ต่างรูปแบบ วัสดุพื้น มาสก์และตราลานบอส รายละเอียดพื้นผูกกับพิกัดโลกและวาดเฉพาะตอนสร้าง chunk

การเปลี่ยนชุดนี้เป็นงานภาพ ขนาดมอนสเตอร์ในโลกยังคำนวณจากข้อมูลเดิม การชน ทางเดิน ประตู จุดเกิด ค่าสถานะ ของดรอป และข้อมูลผู้เล่นไม่ได้เปลี่ยน ต้นไม้/อาคารใช้การจางเมื่อบังผู้เล่นร่วมกับด่านที่ทำไว้แล้ว


เครื่องมือตรวจภาพมอนสเตอร์ตัด socket และใช้ตัวละครจำลอง ไม่บันทึกบัญชีจริง ผลและภาพอยู่ใน `artifacts/stages-v2/{map}/` รวมภาพสถานที่สำคัญ ภาพรวม ภาพมอนสเตอร์ในเกม และทุกท่าทุกทิศ

รันการตรวจเบราว์เซอร์ทีละด่าน เครื่องมือจะยกแท็บทดสอบขึ้นด้านหน้าเพื่อให้การโหลดและการวาดทำงานตามปกติ การเปิดหลายเกมพร้อมกันบนเครื่องนี้เคยทำให้โหลดไม่ทันเวลาที่กำหนด

ตรวจสไปรต์ทั้ง 896 เฟรม: ไม่ซ้ำ ขอบโปร่งใส จุดเท้าคงที่ ขนาดท่ายืนและ version hash ถูกต้อง ตรวจเบราว์เซอร์ว่าตัวเกมเลือกเฟรมตรงกับทิศ/สถานะ ใช้ภาพชุดใหม่แทน fallback และคืนค่า alpha/filter หลังวาดตอนโดนโจมตีหรือตาย ตรวจพื้นทึบและสร้างซ้ำเหมือนเดิม 48 กรณีที่ความละเอียด 1/1.5/2 รวมพื้นที่ซ้อนเมื่อเลื่อน chunk 32 กรณี และหน้าจอมือถือ 390 px

การตรวจทางเดินและจุดเกิดใช้ชุดเดิม 6 ด่าน × 4 seeds รวมมอนสเตอร์ 2,904 จุด ผ่าน การวาดพื้นไม่แก้ tiles/solid/objects ของเซิร์ฟเวอร์

## ใช้งานในเกม

นำเข้าเกม Docker ที่ `http://127.0.0.1:3900` แล้ว โดยรักษาความต่างของหน้าโหลดและระบบอื่นที่มีอยู่ในเกม ตรวจ SHA-256 ตรงกันครบ 63 ไฟล์ เก็บสำเนาก่อนอัปเดตและรายการไฟล์ที่ `artifacts/stages-v2/live-before/`, `deploy-manifest.json` และ `deployed.json` ไม่ต้องรีสตาร์ทเซิร์ฟเวอร์หรือย้ายข้อมูลผู้เล่น รีโหลดหน้าเกมเพื่อรับภาพใหม่

ดูแผนที่โดยไม่เข้าบัญชีที่ `/hunting-review.html` แล้วเลือกด่าน ภาพต้นฉบับและ prompt เก็บไว้สำหรับปรับงานรุ่นต่อไป วัสดุหญ้านำจากชุดหมู่บ้านเดิมมาปรับสีในตัววาดฉาก พื้นที่การต่อสู้ใช้ลายเรียบเพื่อให้เห็นวงเตือนโจมตีชัด
