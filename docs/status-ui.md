# หน้าจัดการสถานะ

ปรับหน้าแจกแต้มเป็นโทนน้ำเงินเข้มและทองให้เข้ากับเกม โดยแสดงแต้มพร้อมใช้ อาชีพ เลเวล และแต้มที่ลงไปแล้วไว้ด้านบน

- คอมพิวเตอร์: ปุ่มแจกแต้มทางซ้าย กราฟและแนวทางอาชีพทางขวา
- มือถือ: เรียงคอลัมน์เดียว ปุ่มแจกแต้มสูงอย่างน้อย 44 px หัวหน้าต่างและปุ่มปิดอยู่กับที่
- แยกค่าพลังปัจจุบันรวมอุปกรณ์ออกจากแต้มที่ลงและโบนัสจากแต้ม
- รองรับ +1, +5, MAX, แจกตามแนวทางอาชีพ และอัปอัตโนมัติด้วยคำสั่งเซิร์ฟเวอร์เดิม
- แสดงค่ารีเซ็ตบนปุ่ม และคงการยืนยันก่อนส่งคำขอรีเซ็ต
- อัปเดตตัวเลขจากอุปกรณ์หรือบัพโดยไม่สร้างหน้าต่างใหม่ เพื่อรักษาตำแหน่งเลื่อนและโฟกัสปุ่ม

ไฟล์หลัก: `public/js/stats.js`, `public/css/style.css`

## ตรวจสอบ

เปิดเซิร์ฟเวอร์พรีวิวและเบราว์เซอร์ Chromium ที่เปิด CDP แล้วรัน:

```powershell
node tools/check-stats-ui-browser.cjs http://127.0.0.1:3918 9362
```

เครื่องมือตัดการเชื่อมต่อ socket และดักคำสั่งแจกแต้ม จึงไม่แก้ไขตัวละครจริง ตรวจคำสั่งแจกแต้ม/แนวทาง/อัตโนมัติ การยืนยันและยกเลิกรีเซ็ต แต้มหมด ค่าเต็มเพดาน แนวทางทั้ง 6 อาชีพ การรักษาโฟกัส/ตำแหน่งเลื่อน และการจัดหน้าจอขนาด 1440, 390 และ 320 px ภาพและรายงานอยู่ใน `artifacts/stats-ui/`
