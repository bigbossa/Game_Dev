# อุปกรณ์และสกิล Lv.120 / 130

ทุกอาชีพใช้ฐานไอเทมเดียวกัน แต่มีรูปลักษณ์อาวุธและลายเครื่องแต่งกายเฉพาะอาชีพ ทั้งธรรมะและอธรรม

| เลเวล | อาวุธ | ชุด 4 ชิ้น | ธรรมะ | อธรรม |
|---|---|---|---|---|
|120|w11|sh8 / pa8 / br8 / sd8|หยกฟ้า งาช้าง ขอบเงินทิพย์|ม่วงทมิฬ ผลึกอเมทิสต์|
|130|w12|sh9 / pa9 / br9 / sd9|งาช้างทอง อักขระปฐมเทพ|ดำแดง ทับทิม ขอบทองแดง|

- ดาบคู่: คมจันทร์จักรพรรดิ → ดาบมงกุฎปฐมเทพ; ลายคมดาบไขว้
- ธนู: คันธนูเขาจันทร์ → มงกุฎขนนกเอลฟ์; ลายใบไม้และอัญมณี
- นักพรต: แส้วงแหวนบัว → แส้บัวติดแผ่นยันต์; ลายบัวและดิ้นขอบอาภรณ์
- ทวน: คมจันทร์คู่ → ตรีศูลปฐมเทพ; ลายเกล็ดมังกรและคมโลหะ

ชุดย้อมตามช่องที่สวมและวางลายตามจุดยึดของเฟรมเดิม ภาพยืน เดิน และโจมตีใช้ระบบปรับสัดส่วนเดิม ไม่มีปีกอุปกรณ์เพิ่มทับปีกอาชีพ ระดับความหายากและจุดแสง Mythic ยังคงแยกจากเลเวลอุปกรณ์

อุปกรณ์ใหม่เข้าตารางดรอปตามเลเวลมอนสเตอร์และบอสโดยอัตโนมัติ ตรวจแหล่งดรอปในแผนที่ M → คู่มือดรอป ระบบตีบวกและคุณภาพ Normal–Mythic ใช้ได้ครบ หากเปิด GM: `/item 120`, `/item 130`, `/set 8`, `/set 9`

## สกิลใหม่

| อาชีพ | Lv.120 (0) | พลังพื้นฐาน | Lv.130 (-) | พลังพื้นฐาน |
|---|---|---|---|---|
|ดาบคู่|หมื่นคมพิพากษา|1000%|จักรพรรดิคู่ผ่าสามภพ|1600%|
|ธนู|ฝนศรกลุ่มดาว|900%|หงส์จักรวาลล้างภพ|1400%|
|นักพรต|ค่ายกลเก้าสวรรค์|800%|มหามณฑลเทพมาร|1300%|
|ทวน|ทวนมังกรถล่มปฐพี|1100%|ทวนมหาเทพดับพิภพ|1700%|

**ไม่ต้องยืนร่าย** ตั้งท่าราว 0.15 วินาที แล้วตัวละครทำท่าจริงบนจอ **แต่ละอาชีพมีท่าของตัวเอง**:

| อาชีพ | ช่อง 0 (Lv.120) | ช่อง - (Lv.130) |
|---|---|---|
| ดาบคู่ | **ดาวห้าแฉก**: พุ่งเข้าจุดเป้าหมาย ลากเส้นดาวห้าแฉกผ่านกลางวง 5 เส้น ทิ้งเงาร่างทุกมุม กระโดดลงกลางดาว · 0.76 วิ | **เทพจุติ**: ทะยานขึ้นฟ้า เงาร่าง 8 ร่างพุ่งเข้าจากรอบวง แล้วดิ่งลงดั่งดาวตก · 1.0 วิ |
| ธนู | **ฝนศรกลุ่มดาว**: ตีลังกากระโดดถอยขึ้นกลางอากาศ ยิงศร 6 ระลอก แต่ละระลอกตกเป็นดาวหนึ่งดวง เส้นกลุ่มดาวต่อกันบนพื้น · 0.9 วิ | **หงส์จักรวาล**: วิ่งโค้งรอบวงศัตรูยิงศรเข้าใส่ 7 ดอก กระโดดสูงกางปีกหงส์ ยิงศรหงส์ดิ่งลงกลางวง · 1.0 วิ |
| นักพรต | **ค่ายกลเก้าสวรรค์**: วาร์ปไปปักยันต์ 3 มุมเป็นสามเหลี่ยมรอบวง เส้นค่ายกลเชื่อมกัน ลอยขึ้นกลางค่ายกลแล้วผนึกกดลง · 0.92 วิ | **มหามณฑล**: ลอยตัวอยู่กับที่ ร่างเทพยักษ์โปร่งแสงขึ้นเหนือวง ประตูปากัว 8 บานสว่างทีละบาน แล้วฝ่ามือเทพตบลง · 1.05 วิ |
| ทวน | **ค้ำทวนกระโดด**: วิ่งพุ่งชาร์จ ค้ำทวนกระโดดข้ามสูงพร้อมหมุนตัว ทวนหมุนวงรอบตัวกลางอากาศ แล้วกระแทกลงกลางวง · 0.8 วิ | **ทวนมังกรเกลียว**: วิ่งวนเกลียวมังกรรอบเป้า แทง 4 ครั้ง แล้วพุ่งทวนจากที่สูงลงกลางวงดั่งหอกเทพ · 0.98 วิ |

ฮิตระหว่างท่าแบ่งดาเมจ 40–55% ตามท่า ส่วนที่เหลือเป็นฮิตปิดท้าย จังหวะทั้งหมดอยู่ใน `ASCENDED_MOVES` (`shared/common.js`) แยกตามอาชีพ

- ดาเมจรวมเท่ากับการระเบิดครั้งเดียวแบบเดิมทุกประการ (แต่ละฮิตหักพลังป้องกันตามสัดส่วนของตัวเอง `opts.defK`) รัศมีเท่าเดิม ทุกฮิตโดนทุกตัวในวง
- หลังฮิตปิดท้าย ตัวละครวาร์ปกลับจุดเดิมแล้วพักท่า 0.65 วินาที เซิร์ฟเวอร์ไม่ย้ายตำแหน่งจริงของผู้ร่าย ระหว่างท่าเดินไม่ได้
- ดาบคู่ใช้ระยะเล็ง 180 / 220 เพื่อพุ่งไปหามอนสเตอร์ (เดิมลงรอบตัว)
- ใช้ปราณ 120 / 180 คูลดาวน์พื้นฐาน 45 / 70 วินาที พลังยังคูณสเต็กสกิล คริ ป้องกัน และตัวคูณ PvE/PvP ตามระบบเดิม
- ค่าจังหวะตั้งที่ `ASCENDED_MOVES` ใน `shared/common.js` เส้นทางการเคลื่อนที่ `AscendedSkills.route` ใน `public/js/ascended-skills.js`

เรียนด้วยแต้มใน K เมื่อเลเวลถึง ช่องลัดเพิ่มเป็น 11 ช่อง โดยเก็บตำแหน่ง 9 ช่องเดิมของเซฟเก่าไว้ ทุกอาชีพเลือกพื้นที่ตามเป้าหรือเมาส์แล้วจำกัดระยะ เซิร์ฟเวอร์ตรึงตำแหน่งและส่งเหตุการณ์เริ่มท่า/ปิดท้าย/ยกเลิก ดาเมจเกิดตามจังหวะฮิตของท่า สตัน ตรึง ตาย ย้ายแผนที่ หรือออกเกมระหว่างท่าทำให้ฮิตที่เหลือยกเลิกทันที ไม่คืนปราณหรือคูลดาวน์

การแสดงผล: ระหว่างท่าวาดอาวุธของอาชีพ (ดาบ / ศร / ยันต์ / ทวน) ไปตามเส้นทาง ฮิตปิดท้ายยังใช้ภาพเฉพาะอาชีพเดิม (ดาบล้อมวงและฟันกากบาท / ฝนศรและหงส์ / มณฑลบัวและยันต์ / ทวนยักษ์ รอยแยก และมังกร) เพิ่มดาวยักษ์ (0) หรือเสาแสงและแผ่นดินแยก (-) ทับ

## ตรวจสอบ

- `npm run check:ascended`: การปลดล็อก การร่าย ดาเมจหมู่ การขัดจังหวะ ระยะ ไอเทมและเซฟเดิม
- `npm run check:spearman`: สกิลทวนเดิมยังเป็นเป้าเดี่ยว
- `npm run check:drops`: คู่มือดรอปตรงกับเซิร์ฟเวอร์
- `node tools/check-ascended-browser.cjs http://localhost:3901 9336`: ภาพ 4 อาชีพ 2 ฝ่าย 2 ระดับ ทุกทิศ/เฟรม ไอคอน และเอฟเฟกต์ในเบราว์เซอร์ CDP ที่เปิดแยกไว้
- ภาพตรวจ: `artifacts/ascended-gallery.png`, `artifacts/ascended-effects.png`
