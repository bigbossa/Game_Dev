# แมพล่า ด่าน 2–7 รุ่น 3

ด่าน 2–7 ใช้ภูมิประเทศที่ออกแบบใหม่ เส้นทางหลักกว้าง 4–6 ช่อง มีทางวนและทางแยกเข้าพื้นที่ล่า 12 จุด บอส 1 จุด และสถานที่สำคัญ 3 แห่งต่อด่าน

| ด่าน | รูปแบบพื้นที่ |
| --- | --- |
| 2 ด่านผาหลิว | ทางคาราวานสองสายระหว่างผา แม่น้ำและสะพานสามช่วง หอสัญญาณและประตูเมฆา |
| 3 ป่ามารสามเศียร | เส้นทางวงรอบบึงพิษ ทางรากไม้ด้านใน ศาลากลางบึงและต้นไม้ผนึก |
| 4 จวนแม่ทัพร้าง | คูเมือง กำแพงแบ่งลาน ทางเชื่อมสองปีก ท้องพระโรง หอระฆัง และสุสาน |
| 5 ประตูเทพยุทธ์ | ระเบียงเขาสามชั้น ทางขึ้นกลางและสองข้าง สระบัวและวิหารยอดเขา |
| 6 วังน้ำแข็งทะเลเหนือ | ทะเลน้ำแข็งแตกเป็นร่องน้ำ สะพานหิน เกาะล่า และวังผลึกทางเหนือ |
| 7 หุบเขาเพลิงทักษิณ | ทางรอบปล่อง วงแหวนลาวา สะพานเข้าสนามบอส แท่นมังกรและเสาเพลิง |

หมู่บ้านด่าน 1 และสนาม PvP คงเดิม รวมถึงเลเวลเข้าแผนที่ ชนิด จำนวน ค่าสถานะ และของดรอปมอนสเตอร์

## ไฟล์หลัก

- `shared/hunting-layouts.js`: จุดเกิด ค่าย ประตู พื้นที่ล่า เส้นทาง สิ่งปลูกสร้างและภูมิประเทศ ใช้ร่วมกันระหว่างเซิร์ฟเวอร์และเบราว์เซอร์
- `shared/world-data.js`: สร้าง collision และวัตถุจาก layout ส่ง payload version 3
- `public/js/hunting-art.js`: ภาพสิ่งปลูกสร้าง Canvas ที่แคชไว้ วงลานบอส และผิวสะพาน
- `public/js/world-art.js`: สีประจำด่านและเชื่อมตัววาดฉาก
- `/hunting-review.html`: ดูแผนที่จริงจาก API เลือกด่าน คลิกแผนที่ เลื่อนและซูมดูรายละเอียด โดยไม่ต้องเข้าบัญชี

ขอบเขตสิ่งปลูกสร้างใช้ collision เต็มฐาน ส่วนหลังคาและยอดมีพื้นที่ยื่นได้ เส้นทางเข้าสถานที่สำคัญไม่ถูกเสาลานบอสบัง การวาดลานใช้พิกัดโลกเพื่อไม่ให้มีรอยต่อข้าม chunk

## ตรวจสอบ

`npm run check:maps` ตรวจ 6 ด่าน × 4 seeds รวมจุดเกิดมอนสเตอร์ 2,904 ตัวด้วยโค้ดวางมอนสเตอร์ของเซิร์ฟเวอร์จริง ตรวจทางเดินจากค่ายไปทุกพื้นที่ล่า บอส ร้านค้า ศิลาวาร์ป ประตูและจุดมาถึง รวมถึงหน้าสิ่งปลูกสร้าง การสร้างซ้ำได้ผลเดิม และ hash ของหมู่บ้าน/PvP ที่ไม่เปลี่ยน

`npm run preview:maps` เปิด preview แยกที่ `http://127.0.0.1:3903/hunting-review.html` โดยไม่ใช้ฐานข้อมูล จากนั้น `npm run check:maps-browser` ใช้ Chromium remote debugger พอร์ต 9336 ตรวจข้อมูล client/server เท่ากัน ภาพไม่ถูกตัด และหน้าจอมือถือ พร้อมบันทึก PNG ใน `artifacts/hunting-v3/`

## ใช้ในเกม Docker

แผนที่ถูกสร้างตอนเซิร์ฟเวอร์เริ่มทำงาน จึงต้อง rebuild/recreate เฉพาะบริการเกมเมื่อเปลี่ยน layout:

```sh
docker compose up -d --build --no-deps --timeout 60 game
```

เซิร์ฟเวอร์รับ SIGTERM แล้วบันทึกผู้เล่นก่อนปิด ตัวละครที่ตำแหน่งเดิมทับฉากใหม่จะกลับค่ายตามการตรวจ `canStand` ที่มีอยู่แล้ว โหลดหน้าเกมใหม่หลังอัปเดตเพื่อใช้ข้อมูล layout และตัววาดฉากชุดเดียวกัน
