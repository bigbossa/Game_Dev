# ทรงผมเฉพาะฝ่ายอธรรม

ภาพธรรมะและช่วงเลเวลเดิมคงไว้ นักพรตไม่ได้เปลี่ยนในงานนี้

| อาชีพ | ช่วงต้น | ช่วงกลาง | ช่วงสูง |
|---|---|---|---|
| ดาบคู่ | Lv.1–39 ผมสั้นปัดข้างปลายแหลม | Lv.40–89 ผมซอยประบ่ากับเปียขมับ | Lv.90–130 ผมยาวปล่อยเป็นชั้นและเปียข้าง |
| นักธนู | Lv.1–49 หน้าม้าตรง สองหางสั้น | Lv.50–99 สองหางลอนประบ่า | Lv.100–130 สองหางยาวปลายม้วน |
| ทวน | Lv.1–29 มวยถักสูง เปิดหน้าผาก | Lv.30–130 มวยสูงต่อเปียยาว | สีและเครื่องแต่งกายพัฒนาตามขั้นเดิม |

ใช้ไฟล์ภาพอธรรมแยก: `public/assets/dualblade-v2/dark-*.png`, `public/assets/archer-v2/dark-*.png`, `public/assets/adharma-hair/spearman-adharma*.png`
ภาพต้นฉบับและพรอมป์ต์ imagegen: `class-art/adharma-hair/`

สร้างใหม่: `npm run adharma-hair`
ตัวสร้างดาบคู่ปรับตำแหน่งภาพอธรรมจากจุดหน้าและเท้ากลับเข้าจุดอ้างอิงเดิม ก่อนตัดใบดาบเก่าเพื่อใช้อาวุธแยกชั้น
ชุดภาพอธรรมแยกทั้งยืน เดิน โจมตี และรูปโปรไฟล์ จุดแสงอุปกรณ์ใช้กรอบภาพของฝ่ายนั้น

ตรวจโดยเปิดเซิร์ฟเวอร์ทดสอบที่ 3901 และ Edge CDP ที่ 9334 จากนั้นรัน:

```
node tools/check-dualblade-v2.cjs
node tools/check-archer-v2.cjs
node tools/check-spearman.cjs
node tools/check-adharma-hair.cjs
```

การตรวจฝ่ายธรรมะใช้ hash ภาพต้นฉบับและ hash ผลวาดจากก่อนแก้ เพื่อยืนยันว่าไม่ได้เปลี่ยนภาพเดิม
`check-adharma-hair.cjs` สร้างภาพเทียบระดับต้น กลาง สูง และพรีวิวทุกทิศของทั้งสามอาชีพ
เปิดพรีวิวด้วย `artifacts/adharma-hair-preview.html`
