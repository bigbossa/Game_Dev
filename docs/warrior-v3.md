# นักรบแนวหน้า V3 — เกราะพิทักษ์

โมเดลวาดใหม่ทั้งธรรมะและอธรรม: หมวกเกราะเปิดหน้า เกราะหนักหลายชั้น ดาบมือเดียวและโล่ทรงเหลี่ยม แหล่งภาพและ prompt จาก built-in imagegen อยู่ใน [class-art/warrior-v3](../class-art/warrior-v3/PROMPTS.md) ใช้แทน V1 พร้อมหมวกที่เคยวาดทับด้วยโค้ด

## เงื่อนไขตามตัวทวน

ใช้ `ModelTiers.LEVELS` และแนวทาง `SpearmanGear`: เลเวล อุปกรณ์ที่สวม เกรด และการตีบวกแยกจากกัน

| เงื่อนไข | รูปลักษณ์ |
|---|---|
| Lv.1 / 15 | ผมสั้นใต้หมวก / เปลี่ยนสีผม |
| Lv.30 | เพิ่มหางผมระดับกลาง |
| Lv.50 | สีผมตามฝ่ายและพู่หมวก |
| Lv.60 / 80 | ผมยาวขึ้น ปีกคู่แรก / ปีกขยาย |
| Lv.100 | ผมขั้นราชัน ปีกขั้นสูง รัศมีหรือเขา และออร่าโล่ |
| Lv.120 | เพิ่มชั้นออร่าโล่ |
| Lv.130 | ร่างสุดท้าย ปีกขั้นสุดท้ายและออร่าประจำฝ่าย |
| `ar[0..3]` | เสื้อ กางเกง ปลอกแขน และเกราะไหล่ แยกสี/วัสดุ/ลายตามชิ้นที่ใส่ รองรับชุดผสมและการถอด |
| `wt` | ดาบและหน้าปัดโล่ใช้ `WarriorWeapons` เช่นเดียวกับไอคอน ครบ 14 ขั้น; รูปทรงกรอบโล่ยังยึดขอบของภาพแต่ละท่า |
| `gg` / `wg` | ขอบแสงตามเกรด จุดแสงบนชิ้นที่สวม และออร่าพุ่งขึ้น ใช้สีและกฎนับเกรดสูงสุดจากระบบกลาง |
| `wp` / `gp` | แสงตามสี +1–10 สายฟ้า/ประกายบนใบดาบ และวงอักขระ +8 ขึ้นไป ตาม `WeaponLook` |

เลเวลสูงไม่ใส่ชุดหรืออาวุธขั้นสูงให้เอง ชุดใช้ `C.ARMOR_SETS` ของชิ้นที่สวมจริง และประเภทวัสดุใช้ `C.armorLookTier` เหมือนทางเดินการแสดงผลของทวน ไม่มีการเปลี่ยนค่าสถานะ เงื่อนไขเลเวลสวมใส่ หรือข้อมูลผู้เล่น

## การประกอบภาพ

`npm run warrior` แพ็ก 8 ทิศ × 4 เฟรมเดิน/ยืน + 3 เฟรมโจมตีของทั้งสองฝ่าย ขนาดเฟรม 320×280 จุดเท้า (160,252) ตามด้วยการตรวจตำแหน่งหมวกและสร้างมาสก์อุปกรณ์แยกช่องใน `public/assets/warrior-v3/`

`tools/build-warrior-gear.cjs` ใช้จุดอ้างอิงอาวุธและขอบเขตผิวโลหะจริงเพื่อแยกใบดาบ มือและด้ามอยู่ในภาพเดิม ขอบเขตใบหน้าปกป้องสีผิว ดวงตา และปาก การวาดแต่ละเฟรมใน `warrior-gear.js` มีแคชที่รวมช่องอุปกรณ์ทั้งสี่และขั้นอาวุธ ไม่อ่านพิกเซลใหม่ทุกเฟรม แสงเกรดและตีบวกวาดแยกจากพื้นผิวชุด

ทั้งในฉากเกม ภาพตัวละครในกระเป๋า และภาพเลือกตัวละครใช้ `WarriorLook` ตัวเดียวกัน เอฟเฟกต์ดับเมื่อเสียชีวิต และ `noGlow` ปิดเอฟเฟกต์สำหรับเงาตัวละคร
