# หมู่บ้านเซียนน้อย — หุบเขาสองวิถี

แมพแรกของธรรมะ–อธรรม Online ใช้สภาพแวดล้อมวาดลงสีแบบ 2D wuxia ให้เข้ากับโมเดลนักพรตและนักรบรุ่นใหม่ นำไปใช้ใน runtime แล้วด้วย `shared/village-map.js` และ `public/js/village-art.js` ภาพใน `map-art` เป็น concept และต้นฉบับ assets; ภาพจาก renderer จริงอยู่ใน `artifacts/village-v2`.

## ภาพรวม

หมู่บ้านกลางหุบเขาที่ผู้เล่นสองฝ่ายใช้ร่วมกัน บรรยากาศช่วงเช้าสงบและมีชีวิตชีวา ใจกลางเป็นลานหินหยินหยาง มีต้นท้อและศาลาหลังคาหยกเป็นจุดจำ ถนนหลักเชื่อมสะพานหินทางตะวันตกผ่านหมู่บ้านไปยังประตูด่านทางตะวันออก พื้นที่รอบนอกค่อย ๆ เปลี่ยนจากทุ่งโล่งเป็นป่าไผ่ ค่ายโจร และลานหินอันตราย

ชื่อแมพในเกมยังใช้ “หมู่บ้านเซียนน้อย”; “หุบเขาสองวิถี” เป็นชื่อแนวคิดทางศิลป์

## โครงสร้างแมพ

อ้างอิงแมพเดิม `village` ขนาด 128 × 96 ช่อง, TILE 48, ช่วงเลเวล 1–20 มีบอส Lv.25 แยกจากเส้นทางผู้เล่นใหม่ จุดต่อไปคือด่านผาหลิวทางตะวันออก

| พื้นที่ | รูปลักษณ์ | หน้าที่ |
|---|---|---|
| ลานกลางหมู่บ้าน | หินสีงาช้าง ลายหยินหยาง ศาลาหยก ต้นท้อ | จุดเกิดและพักในเขตปลอดภัย ใช้ร่วมกันสองฝ่าย |
| ตลาดยาฝั่งตะวันตกของลาน | บ้านไม้ โอ่งยา แผงสมุนไพร ผ้าใบสีครีม | ร้านยา อยู่ใกล้จุดเกิดและทางออก |
| โรงตีเหล็กฝั่งตะวันออกของลาน | เตาหลอมขนาดเล็ก ทั่ง ชั้นวางอาวุธ | อ่านหน้าที่ได้จากรูปทรงอาคาร |
| ศิลาวาร์ปริมลาน | เสาหยกขนาดเล็ก แสงฟ้าอ่อน | จุดเดินทางเดิม มีพื้นที่ยืนรอบเสา |
| สะพานเมฆาข้ามลำธาร | สะพานหินเตี้ย น้ำหยก กอไผ่ | จุดจำฝั่งตะวันตกและทางไปทุ่งฝึก |
| ทุ่งน้ำค้าง / สวนเห็ด | หญ้าเขียวอ่อน ดอกไม้เล็ก โขดหินเตี้ย | ภูตน้ำค้าง Lv.1 และเห็ด Lv.3 |
| สวนร้าง / ชายป่า | พุ่มไม้เป็นกลุ่ม รั้วไม้เก่า พื้นที่ต่อสู้โล่ง | หมูป่า Lv.5 และงู Lv.8 |
| ป่าไผ่เงาจันทร์ | ไผ่เข้มขึ้น ร่มเงาเย็น เส้นทางยังอ่านง่าย | หมาป่า Lv.12 |
| ค่ายโจร / ลานผาพยัคฆ์ | ศาลเก่าชำรุด เต็นท์ไม้ โขดหิน | โจร Lv.16 และเสือ Lv.20 |
| ถ้ำหมูป่าเกราะเหล็กด้านเหนือ | เวิ้งหินขนาดกว้าง รั้วหัก รอยเท้าขนาดใหญ่ | บอส Lv.25 เข้าทางแยก ไม่ขวางถนนหลัก |
| ประตูด่านตะวันออก | ซุ้มไม้หลังคาหยกและหน้าผา | เส้นทางไปแมพที่สอง |

## ภาษาภาพ

- พื้นดินและพืชใช้สีอ่อนกว่าตัวละคร ลดลายจุดเล็ก ๆ เพื่อให้อาวุธ ชุด และวงเตือนสกิลอ่านง่าย
- สีหลัก: หยก `#456F64`, หญ้า `#819563`, หิน `#D5C6A4`, ไม้ `#89603D`, หลังคา `#294F50` และดอกท้อ `#D994A8`
- รายละเอียดธรรมะใช้ขาว–ฟ้า–ทอง ส่วนอธรรมใช้ดำ–แดง–ทอง เป็นธงเล็กและเครื่องประดับที่มีน้ำหนักเท่ากัน หมู่บ้านเป็นพื้นที่กลาง
- อาคารเตี้ย สัดส่วนกะทัดรัด โค้งหลังคาแบบยุทธภพ แสงจากซ้ายบนและเงานุ่มสอดคล้องกับโมเดล
- ขอบน้ำ ขอบดิน และรอยต่อหญ้าเป็นเส้นธรรมชาติ ไม่เห็นช่องสี่เหลี่ยมต่อกันชัด
- ทางหลักกว้างประมาณ 4–6 ช่อง ทางรอง 3–4 ช่อง พื้นที่ต่อสู้มีจุดโล่งและทางกลับหมู่บ้านที่สังเกตง่าย
- ต้นไม้หนาแน่นอยู่ขอบพื้นที่ หลังคาและยอดไม้ควรจางลงเมื่อบังตัวละครในขั้นพัฒนา

## ภาพตัวอย่าง

1. `map-art/village-v2/overview-concept.png` — ภาพรวมหมู่บ้านและพื้นที่ผจญภัย
2. `map-art/village-v2/plaza-concept.png` — มุมใกล้ลานหมู่บ้านและสัดส่วนตัวละคร

สร้างด้วย built-in image_gen โดยใช้ภาพแมพเดิมเป็นข้อมูลมุมมอง และภาพนักพรต v2 เป็นตัวอย่างงานวาด; prompt เต็มอยู่ใน `map-art/village-v2/PROMPTS.md`

## เมื่อนำไปพัฒนา

ภาพ concept ไม่ควรถูกยืดเป็นฉากหลังทั้งแมพ ต้องแยกเป็นพื้น terrain ที่ต่อกันได้ อาคาร ต้นไม้ สะพาน ของตกแต่ง และจุดเอฟเฟกต์ แล้ววางตามระบบ chunk และการบังภาพของเกม

ตำแหน่งภาพและข้อมูลเดินชน เขตปลอดภัย จุดเกิดมอนสเตอร์ ร้านค้า และทางออกใช้ layout เดียวกันทั้ง browser และ server โดยคงสถิติมอนสเตอร์เดิม แนวคิดค่ายโจรและถ้ำใช้พื้นที่เกิดและลานโขดหินในรุ่นนี้ ยังไม่ได้เพิ่มเต็นท์หรือปากถ้ำแยกชิ้น.

## Runtime และการตรวจสอบ

- `npm run village` สร้าง 12 props และ 3 terrain assets จากต้นฉบับใน `map-art/village-v2` ไปยัง `public/assets/village-v2`.
- `npm run check:village` ตรวจการเดินถึงจุดสำคัญ 84 รายการจาก 4 seed, การวางมอนสเตอร์จริง 564 ตัว, สะพาน/น้ำ, อาคาร, เขตปลอดภัย และจุดเกิดแมพอื่น.
- `npm run check:monster-skills` ตรวจระบบสกิลมอนสเตอร์ 230 สถานการณ์.
- `npm run check:village-browser -- http://127.0.0.1:3900 9351` ตรวจเกมที่เสิร์ฟจริงผ่าน Chrome CDP port 9351: assets, collision ตรงกับ server, click paths, keyboard movement, roof fade, deterministic terrain และ browser errors. ใช้ตัวละครจำลองที่ตัด socket แล้ว ไม่บันทึกบัญชีผู้เล่น.
- ภาพตรวจสอบ: `artifacts/village-v2/village-in-game.png`, `village-bridge.png`, `village-overview.png`; ผล browser อยู่ที่ `check.json`.
- `docker compose up -d --build --no-deps --timeout 30 game` อัปเดตเฉพาะ service เกม.
- ผู้เล่นที่บันทึกตำแหน่งไว้บนสิ่งกีดขวางใหม่จะถูกย้ายไปจุดเกิดตามระบบตรวจตำแหน่งเดิมเมื่อเข้าเกม.
