# จัดวางวัตถุครบ 8 แผนที่ — 26 ตุลาคม 2026

ค่ายด่าน 2–7 แยกร้านช่างตีดาบกับร้านขายยาไว้คนละฝั่งด้านบน ร้านตีบวกด้านล่างขวา ศิลาเคลื่อนย้ายด้านซ้าย และบ้านพักหนึ่งหลังด้านล่างซ้าย เปิดลานกลางกับแนวทางเข้าประตู จุดบริการและ collision ใช้พิกัดเดียวกันทั้งเซิร์ฟเวอร์และเบราว์เซอร์ ฐานร้านกว้าง 4 × 2 ช่อง

ต้นไม้ หิน และของตกแต่งสุ่มใช้ตารางตรวจระยะห่างแบบวงรีจากตำแหน่งจริง รวมระยะเยื้องของภาพ เพื่อป้องกันพุ่มไม้ซ้อนแน่น ตรวจระยะเฉพาะตอนสร้างแมพ ไม่มีงานเพิ่มต่อเฟรม ตำแหน่งสร้างซ้ำได้ด้วย seed เดิมและยังเคารพพื้นที่เว้นทาง สะพาน ค่าย ลานบอส และจุดล่า

หมู่บ้านใช้ระยะตามชนิดภาพ โดยเก็บอาคารหลักและสวนในค่ายเดิม สนาม PvP จับคู่วัตถุธรรมชาตินอกฐานแบบสะท้อนซ้าย–ขวารวมจุดชน และเลือกสีต้นไม้ตามฝ่าย ต้นไม้ผนึกในด่านป่ามารเลื่อนจากช่อง (56,7) เป็น (56,9) ให้ภาพอยู่ในขอบแผนที่ เสาลานบอสเว้นฐานและทางเข้าสถานที่สำคัญ

## การตรวจ

- `node tools/check-object-placement.cjs`: 8 แมพ × 4 seeds ตรวจการสร้างซ้ำ เส้นทางจากจุดเกิดทั้งสองฝ่ายถึงลานบอส ร้านค้า ประตู จุดชน ระยะต้นไม้ และคู่สมมาตร PvP
- `node tools/check-hunting-maps.cjs`: ด่านล่า 6 แมพ × 4 seeds ตรวจเส้นทาง พื้นที่ล่า สถานที่สำคัญ และการเกิดมอนสเตอร์จริง 2,904 ตัว พร้อม hash ภูมิประเทศหมู่บ้าน/PvP
- `node tools/check-village.cjs`: หมู่บ้าน 4 seeds สะพาน ทางข้ามแม่น้ำ และจุดเกิดจริง
- `node tools/check-object-placement-browser.cjs http://127.0.0.1:3923 9362`: หน้ารีวิวครบ 8 แมพ ข้อมูลภาพ/จุดชนตรง API ภาพอาคารค่ายไม่ทับกัน โหลดภาพครบ และหน้าแคบ 390px ไม่ล้น

เปิด preview แบบไม่บันทึกผู้เล่นด้วย `node tools/preview-village.cjs 3923` และเปิด Edge/Chromium ที่มี debugger พอร์ต 9362 ก่อนตรวจเบราว์เซอร์ ภาพตรวจและรายงานอยู่ใน `artifacts/map-placement/` หน้า `/hunting-review.html` ใช้ข้อมูลจาก API จริง รองรับทั้งหมู่บ้าน ด่านล่า และ PvP พร้อมล้างแคชพื้นเมื่อเปลี่ยนแมพ

เซิร์ฟเวอร์ต้องเริ่มใหม่เพื่อสร้างวัตถุและจุดชนชุดใหม่ ผู้เล่นควรรีโหลดหน้าเกมเพื่อรับตำแหน่งร้านค้าใหม่ด้วย ระบบโหลดตัวละครตรวจ `canStand` และใช้จุดเกิดหากตำแหน่งที่บันทึกทับวัตถุใหม่
