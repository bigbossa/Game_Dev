# สกิลอาชีพ (ออกแบบใหม่ 21 ตุลาคม 2026)

ข้อมูลสกิลอยู่ที่ `CLASSES.<อาชีพ>.skills` ใน `shared/common.js`
ผลของสกิลคำนวณที่ `castSkill` ใน `server/world.js`
ภาพเอฟเฟกต์อยู่ที่ `SkillFX.render.<id>` ใน `public/js/skill-fx.js`
ไอคอน canvas อยู่ที่ `icon()` ใน `public/js/hud.js`

## ระบบบัพ

- บัพเก็บที่ `p.buffs[skillId] = { until, k, guard, dmg, crit, critDmg, aspd, echo, sure }`
  ใช้ `World.addBuff`, `buffVal` และ `buffList`
- ถ้าบัพเดิมยังไม่หมดและแรงกว่า บัพที่อ่อนกว่าจะไม่เขียนทับ
  ส่วนบัพต่างชนิดกันซ้อนกันได้
- `guard` ลดดาเมจรวมกับออปชันอุปกรณ์ ลดได้สูงสุด 70%
  `dmg` คูณดาเมจที่ทำได้
- คริติคอลรวมบัพสูงสุด 85% (`critOf`)
  `aspd` มีผลกับการโจมตีปกติ (ปุ่ม 1)
- `snapshot.me.bf` ส่งรายการบัพที่ทำงานอยู่ไปให้ HUD
  แถบบัพใต้กรอบผู้เล่นแสดงไอคอน วินาทีที่เหลือ และเวลาที่ใช้ไปแล้ว
  ค่า `crit` และ `aspd` ใน snapshot รวมบัพแล้ว
  ไคลเอนต์จึงคำนวณคูลดาวน์โจมตีปกติตรงกับเซิร์ฟเวอร์
- บัพหายเมื่อเกิดใหม่หลังตาย
- เกราะแตก (`breakUntil`, `breakK`) ลดป้องกันของเป้า ทั้งมอนสเตอร์และผู้เล่น
  เกราะแตกไม่ซ้อนกัน ใช้ค่าที่แรงที่สุด

## เซฟเก่า

`C.SKILL_VER = 2` เซฟสกิลเวอร์ชันก่อนหน้าจะได้แต้มสกิลคืนทั้งหมด
แล้วระบบแจกแต้มให้อัตโนมัติ และแถบสกิลจะกลับเป็นค่าเริ่มต้น
ไม่ต้องลบเซฟ ใช้ได้กับทุกอาชีพ
