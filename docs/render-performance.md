# ปรับประสิทธิภาพการวาดเกม — 25 ตุลาคม 2026

ลดงานซ้ำใน client โดยคงความละเอียดฉาก ตัวละคร และเอฟเฟกต์สกิลเดิม:

- ชื่อตัวละคร มอนสเตอร์ และป้าย NPC วาดเป็นภาพเก็บไว้ตามข้อความ สี ฟอนต์ และระดับ zoom/DPI ใช้แคช LRU สูงสุด 256 รายการและ 4 MiB; เปลี่ยนชื่อ เลเวล PvP แต้มชั่วร้าย aggro หรือโหลดฟอนต์เสร็จจะวาดใหม่
- HUD ไม่สร้างชื่อเป้าหมายหรือเขียนเลือด/ปราณ/EXP/เลเวล/tooltip ซ้ำเมื่อค่าเท่าเดิม; เลือดและคูลดาวน์ยังอัปเดตทุกเฟรมเมื่อเปลี่ยน
- อนุภาคและตัวเลขดาเมจนอกขอบจอข้ามเฉพาะคำสั่งวาด ยังคำนวณตำแหน่งและอายุ รวมขอบประกายที่พาดเข้าจอและเผื่อ screen shake; ไม่ข้าม callback สกิล พื้นที่เตือน หรือจังหวะโจมตี
- ใช้อาร์เรย์อนุภาคและตัวเลขเดิมในการล้างรายการหมดอายุ ลดการจัดสรรหน่วยความจำระหว่างต่อสู้

## ผลทดสอบ

ทดสอบ renderer จริงใน Edge headless ที่ 1280×900, DPR 1 บนเครื่องพัฒนาเดียวกัน ฉากละ 7 วินาที ตัดช่วงอุ่นแคช 2 วินาที ไม่มีบัญชีผู้เล่นหรือการบันทึกข้อมูล ทดสอบ HUD จริงผ่านการเรียกจาก benchmark; ไม่ใช่การทดสอบ latency ของเซิร์ฟเวอร์

| ตัวชี้วัด | ก่อน | หลัง |
| --- | ---: | ---: |
| เวลาทำงาน HUD/เฟรม ฉากมอนสเตอร์ 48 ตัว | 0.270 ms | 0.075 ms |
| DOM mutations/เฟรม เมื่อสถานะคงเดิม | 8.04 | 0 |
| การวาดขอบข้อความ/เฟรม ฉากมอนสเตอร์ 48 ตัว | 50 | 0 |
| การวาดขอบข้อความ/เฟรม ฉากอนุภาคหนาแน่น | 90.61 | 6.88 |
| เวลาเฟรม P95 ฉากอนุภาคหนาแน่น | 50.0 ms | 33.5 ms |
| FPS เดิน / มอนสเตอร์ 48 ตัว / อนุภาคหนาแน่น | 45.0 / 38.8 / 30.3 | 43.8 / 38.1 / 30.8 |

FPS เฉลี่ยยังใกล้เคียงเดิมและมีความผันผวนของเครื่องทดสอบ จึงไม่ถือเป็นหลักฐานว่า FPS เพิ่มขึ้นทุกเครื่อง สิ่งที่ลดได้ชัดคือการเขียน DOM และการวาดข้อความซ้ำ ฉากอนุภาคเป็น stress test สังเคราะห์: มอนสเตอร์ 48 ตัว และปล่อยอนุภาค 1,200 ชิ้นทุก 250 ms จาก 12 จุด โดย 10 จุดอยู่นอกจอ ไม่ใช่จำนวนศัตรูหรือสกิลในสถานการณ์ปกติ

ตรวจ browser 15 กรณี: ตัวตน/เลือด/เลเวลเปลี่ยน, ซ่อนและคืนเป้าหมาย, คูลดาวน์เริ่มและหมด, แคชชื่อและฟอนต์, เปรียบเทียบพิกเซลก่อน/หลัง culling รวมประกายที่พาดขอบจอ, การหมดอายุ และ callback สกิล ยังผ่านชุด combat เทวทัณฑ์ 22 กลุ่ม และ ascended 120 กรณี

## รันทดสอบซ้ำ

เปิด preview แบบไม่บันทึกบัญชี และ Chromium/Edge พร้อม CDP จากนั้น:

```powershell
node tools/preview-village.cjs 3918
# รันอีก terminal; 9362 คือพอร์ต CDP ของเบราว์เซอร์ทดสอบ
node tools/benchmark-render.cjs current http://127.0.0.1:3918 9362 --verify
```

รายงาน JSON และภาพอยู่ที่ `artifacts/performance/` (gitignored) ตัวเลือก `--baseline` ใช้ snapshot เดิมของ `main.js`, `hud.js`, `fx.js` ใน `artifacts/performance/before-js/` ผ่าน CDP interception โดยไม่เขียนทับ source ปัจจุบัน รายงานรอบนี้คือ `before-final.json`, `after-final.json`, `optimized.png`
