# นักรบแนวหน้า V4 — ผู้พิทักษ์ยุทธภพ

ออกแบบใหม่โดยอ้างอิงสัดส่วน สี และเส้นของตัวละครทวนที่มีอยู่ ใช้มวยผมเปิดหน้า ชุดผ้าซ้อนเกราะ และดาบกับโล่ ฝ่ายธรรมะใช้เงิน–ขาว–หยก–น้ำเงิน ฝ่ายอธรรมใช้ดำ–แดงเข้ม แยกภาพเดินและโจมตีครบ 8 ทิศของทั้งสองฝ่าย

## เลเวลและอุปกรณ์

ใช้เกณฑ์เลเวลจาก `ModelTiers` เหมือนอาชีพทวน สีผมเปลี่ยนที่ Lv.15/30/50/60/80/100/130; Lv.30 เริ่มเพิ่มปอยผมผูกยาวที่ท้ายทอย ปีก รัศมี เขา และออร่าใช้ระบบกลางเดิม การวาดปอยผมหลีกเลี่ยงใบหน้าและดวงตา ไม่มีพู่หมวกทับมวยผม

เสื้อ กางเกง ปลอกแขน และเกราะไหล่เปลี่ยนแยกตาม `ar[0..3]` รองรับชุดผสมและการถอดกลับ ดาบและโล่ใช้ขั้นอาวุธ `wt` สีและลายชุดไม่เปลี่ยนเพราะเลเวลอย่างเดียว เกรดและการตีบวกวาดเป็นเอฟเฟกต์แยกจากพื้นผิวอุปกรณ์ และปิดเมื่อเสียชีวิตหรือใช้ `noGlow`

## ไฟล์และการตรวจ

- โมเดลและมาสก์อุปกรณ์: `public/assets/warrior-v4/` เฟรมขนาด 320×280 จุดเท้า (160,252)
- ตัววาดร่วมในเกม กระเป๋า และภาพเลือกตัวละคร: `public/js/warrior-look.js` กับ `public/js/warrior-gear.js`
- ห้องลองโมเดล: `/warrior-review.html` เลือกฝ่าย เลเวล อุปกรณ์ เกรด ตีบวก และท่าทางได้โดยไม่ใช้บัญชี
- `node tools/check-warrior-art.cjs` ตรวจ 112 เฟรม ความโปร่งใส จุดเท้า ภาพสะท้อน 8 ทิศ มาสก์อุปกรณ์ และภาพบุคคล
- `node tools/check-warrior-model.cjs http://127.0.0.1:3902 9335` ตรวจการสวม–ถอดแต่ละช่อง อาวุธ 28 แบบ สีผม 16 แบบ สีผิวหน้า และเอฟเฟกต์ในเบราว์เซอร์
- `node tools/check-warrior-browser.cjs http://127.0.0.1:3902 9335` ตรวจภาพเลือกตัวละคร เดสก์ท็อป/มือถือ สกิล และไอคอนในตัวเกม

ผลตรวจภาพเก็บใน `artifacts/warrior-v4/` ประวัติแบบหมวกเกราะเดิมอยู่ใน [warrior-v3.md](warrior-v3.md)

## ส่วนที่เติมจากการเทียบตัวทวน

- Lv.30 เริ่มมีวงตราโล่ใต้เท้า; Lv.60 เพิ่มชายผ้าพลังปราณด้านหลัง; Lv.100/130 เพิ่มจำนวนชั้น โดยใช้ช่วงเลเวลเดียวกับทวนและไม่บังใบหน้า
- ดาบโจมตีเป้าเดี่ยวหันตามเป้าที่ล็อก ตรวจสิ่งกีดขวางก่อนใช้ MP/คูลดาวน์ และตรวจซ้ำตอนกระทบ เป้าหลุดระยะ ย้ายแมพ ตาย หรือผู้ร่ายถูกหยุด จะยกเลิกจังหวะนั้น
- เซิร์ฟเวอร์ส่ง `frontlineHit`/`frontlineCancel` พร้อมหมายเลขการร่าย ให้ภาพกระแทกแสดงหลังยืนยันจริง และป้องกันคำยืนยันเก่าไปกระทบท่าใหม่
- ล้างเอฟเฟกต์นักรบเมื่อถูกหยุด ตาย หรือเปลี่ยนแมพ เช่นเดียวกับการยกเลิกท่าทวน
- การเปลี่ยนผมตามเลเวล ชุดแยกชิ้น อาวุธ เกรด ตีบวก ปีก สกิลขั้นสูง และพรีวิวในกระเป๋ามีอยู่แล้วและยังใช้ต่อ ไม่คัดลอกท่าโจมตีทวนหรือเปลี่ยนค่าสมดุลอาชีพ

`npm run check:warrior-parity` ตรวจ 60 กรณีโจมตีทั้งสองฝ่ายและ PvE/PvP รวมผนังที่บังหลังเริ่มร่าย การหลุดระยะ ติดราก หมายเลขร่ายเก่า การล้างเอฟเฟกต์ และช่วงเลเวล

ต้นฉบับสร้างด้วย built-in imagegen และเก็บพร้อม prompt ใน [class-art/warrior-v4/PROMPTS.md](../class-art/warrior-v4/PROMPTS.md)

## วิชาช่วง Lv.100–130

ข้อมูลและระบบต่อสู้มีวิชาเหล่านี้อยู่แล้ว แต่คัมภีร์เดิมจัดการ์ดตามเลเวลเริ่มเรียน ทำให้ขั้นอัปเกรด Lv.100–130 อยู่ใต้สกิลเลเวลต่ำ ส่วนท่าใหม่อยู่ท้ายรายการ เพิ่มรายการรวมด้านบนคัมภีร์นักรบแนวหน้า ให้กดไปยังการ์ดหรือขั้นที่ตรงกัน พร้อมสถานะยังไม่ปลดล็อก/ยังไม่เรียน/ยังไม่อัปขั้น/ยังไม่วางปุ่ม/ปุ่มที่ใช้

| เลเวล | อัปขั้นวิชาเดิม | วิชาใหม่ |
| --- | --- | --- |
| 100 | ดาบผ่าเกราะขุนพล | — |
| 110 | แนวโล่ขุนพล | — |
| 120 | โล่สะเทือนภูผา | สัตย์พิทักษ์; โล่พิทักษ์ทลายแนว (ค่าเริ่มต้นปุ่ม 0) |
| 130 | คำรามมหาขุนพล; ปราการมหาขุนพล | ดาบมหาปราการ; ป้อมปราการถล่มฟ้า (ค่าเริ่มต้นปุ่ม -) |

สัตย์พิทักษ์และดาบมหาปราการเป็นสกิลเสริม ให้เรียนแล้วเลือกปุ่มบนการ์ด การแสดงรายการรวมไม่เรียนสกิลแทนผู้เล่น ไม่ใช้แต้ม และไม่เปลี่ยนปุ่มที่จัดไว้

ทดสอบ `check-warrior-browser.cjs`: รายการครบ 9 ขั้นที่ Lv.99/100/110/120/130, การกระโดดไปขั้น Lv.100, สถานะปุ่ม, คำขอเรียน, การรักษาแถบเดิม และขนาดมือถือ 390px; เอฟเฟกต์ครบ 13 สกิลและไม่มี browser error ผ่านชุดต่อสู้ warrior 427 casts และ ascended 120 กรณีด้วย
