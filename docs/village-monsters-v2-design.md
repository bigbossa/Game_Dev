# มอนสเตอร์หมู่บ้านเซียนน้อย — แบบใหม่

ชุดออกแบบสำหรับแมพแรก 7 มอนสเตอร์ทั่วไปและบอส 1 ตัว ใช้งานวาดลงสี 2D chibi wuxia ให้เข้ากับลานหยินหยาง อาคารหลังคาหยก และตัวละครรุ่นใหม่

สถานะ: มอนสเตอร์ทั่วไปทั้ง 7 ตัวยังเป็น concept design ส่วนบอส `kingboar` มีโมเดล 2D sprite ใช้ในเกมแล้ว 32 เฟรม (8 ทิศ × ท่าเดิน A / ยืน / เดิน B / โจมตี) โดยคงระบบต่อสู้ เลเวล และของดรอปเดิม ภาพอยู่ใน `monster-art/village-v2` สร้างด้วย built-in image_gen; prompt แนวคิดอยู่ใน `PROMPTS.md` และ prompt สไปรต์บอสอยู่ใน `KINGBOAR-SPRITES-PROMPTS.md`.

ภาพรวมเรียงจากซ้ายไปขวา: แถวบน Lv.1, 3, 5, 8; แถวล่าง Lv.12, 16, 20, บอส Lv.25

## บอส

โครงร่างเน้นหัวและไหล่ใหญ่ ให้เห็นเขี้ยว แผงคอ และแผ่นเกราะจากมุมกล้องเกม เกราะคลุมหัวไหล่และหลัง เปิดหน้า ขา และสีขนไว้ ชิ้นหยกกับเชือกแดงเป็นเพียงจุดแต้มสีเพื่อไม่ให้กลืนกับต้นไม้และวงเตือนบนพื้น

ภาพละเอียดประกอบด้วยมุมหลัก มุมหลัง ท่าก้มเตรียมพุ่ง และรายละเอียดวัสดุ ท่าพุ่งเป็นแนวทาง animation เท่านั้น การเพิ่มสกิลพุ่งจริงต้องออกแบบระยะ วงเตือน และ cooldown แยกจากงานภาพนี้

## แนวทางนำเข้าเกม

- ใช้ ID และช่วงเลเวลเดิม เพื่อเชื่อมตำแหน่งเกิด ชื่อ และของดรอปเดิมได้
- ผลิต sprite โปร่งใสแยกต่อชนิด ไม่ตัดภาพ concept ที่มีหลายมุมไปใช้เป็นเฟรมเดินโดยตรง
- ระบบเดิมรองรับ 8 ทิศ × 3 เฟรมเดินผ่าน `tools/build-monsters.js` และ `public/assets/monsters/index.json`; ควรสร้างและตรวจความต่อเนื่องของท่าทางก่อนนำเข้า
- คุมจุดยึดเท้าคงที่และขอบโปร่งใส ไม่ใส่เงาพื้นหรือกลุ่มแสงหนาจนบังวงโจมตี
- บอสต้องใหญ่กว่าหมูป่าปกติชัดเจน ตรวจสัดส่วนกับนักพรตและพื้นที่ลานบอสในเกมก่อนใช้งานจริง

## โมเดลบอสที่ใช้งานจริง

- `npm run kingboar`: ตัด silhouette แบบรักษา alpha จาก `kingboar-south-source.png` และ `kingboar-north-source.png`; จัดจุดเท้าและ scale เดียวกันต่อทิศตลอด animation เป็น `public/assets/monsters/kingboar-v2.png` พร้อม metadata ใน `index.json`.
- ความสูงภาพยืน 132 world pixels ก่อน scale มอนสเตอร์ของ renderer; ทิศใน sheet คือ S, SE, E, NE, N, NW, W, SW. ท่าโจมตีใช้สัญญาณ melee เดิม ไม่เพิ่มสกิลพุ่งใหม่.
- `npm run check:kingboar`: ตรวจ 32 เฟรมไม่ซ้ำ ขอบโปร่งใส จุดเท้าคงที่ เลเวลและการผูกบอสแมพแรก.
- `npm run check:kingboar-browser -- http://127.0.0.1:3900 9351`: ตรวจ renderer ของเกมจริงผ่าน Chrome CDP ทั้ง 32 ท่า/ทิศ การตอบสนองเมื่อโดนตีและจางหาย และยืนยันว่าไม่ได้ใช้โมเดล procedural เดิม. ใช้ตัวละครจำลองที่ตัด socket ไม่เขียนบัญชีผู้เล่น.
- ภาพและผลตรวจ: `artifacts/kingboar-v2/kingboar-poses.png`, `kingboar-in-game.png`, `kingboar-attack.png`, `check.json`.
