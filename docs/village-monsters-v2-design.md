# มอนสเตอร์หมู่บ้านเซียนน้อย — แบบใหม่

ชุดออกแบบสำหรับแมพแรก 7 มอนสเตอร์ทั่วไปและบอส 1 ตัว ใช้งานวาดลงสี 2D chibi wuxia ให้เข้ากับลานหยินหยาง อาคารหลังคาหยก และตัวละครรุ่นใหม่

สถานะ: มอนสเตอร์ทั่วไปทั้ง 7 ตัวและบอส `kingboar` มีโมเดล 2D sprite ใช้ในเกมแล้ว ตัวละ 32 เฟรม (8 ทิศ × ท่าเดิน A / ยืน / เดิน B / โจมตี) รวมมอนสเตอร์ทั่วไป 224 เฟรม โดยใช้ระบบต่อสู้ เลเวล ขนาด และของดรอปเดิม ภาพอยู่ใน `monster-art/village-v2` สร้างด้วย built-in image_gen; prompt แนวคิดอยู่ใน `PROMPTS.md`, prompt สไปรต์ทั่วไปอยู่ใน `SPRITES.json` (นำ `prompt` ต่อด้วย `Subject:` และ `species[].subject`) และ prompt สไปรต์บอสอยู่ใน `KINGBOAR-SPRITES-PROMPTS.md`.

## ตัวละครทั้งชุด

| ID / เลเวลเดิม | ชื่อ | แบบใหม่และจุดจำ |

| mushroom / 3 | เห็ดพิษปีศาจน้อย | หมวกเห็ดแดงจุดงาช้าง ก้านอวบ ตาใต้ปีกหมวก เท้ารากไม้ |
| boar / 5 | หมูป่าเขี้ยวเลื่อย | ขนเกาลัด แผงขนหยัก เขี้ยวสั้นเป็นฟันเลื่อย สี่ขากีบแยก |
| greensnake / 8 | อสรพิษหญ้าเขียว | เกล็ดหยก ลายใบไผ่ ท้องเหลืองอ่อน ขดตัวชูหัว ตาอำพัน |
| wolf / 12 | หมาป่าเงาจันทร์ | ขนถ่านอมคราม อกและคิ้วเงินม่วง ลายจันทร์เสี้ยว ทรงตัวเพรียว |
| bandit / 16 | โจรหมวกฟาง | หมวกสาน เสื้อผ้ามอส–น้ำตาล ผ้าคาดแดงหม่น ดาบโค้ง ถุงเหรียญ |
| mountaintiger / 20 | เสือภูเขาลายดำ | สีทองส้ม ลายดำชัด อกครีม หางปล้อง ท่าต่ำไหล่กว้างกว่าหมาป่า |

ภาพรวมเรียงจากซ้ายไปขวา: แถวบน Lv.1, 3, 5, 8; แถวล่าง Lv.12, 16, 20, บอส Lv.25

## บอส

โครงร่างเน้นหัวและไหล่ใหญ่ ให้เห็นเขี้ยว แผงคอ และแผ่นเกราะจากมุมกล้องเกม เกราะคลุมหัวไหล่และหลัง เปิดหน้า ขา และสีขนไว้ ชิ้นหยกกับเชือกแดงเป็นเพียงจุดแต้มสีเพื่อไม่ให้กลืนกับต้นไม้และวงเตือนบนพื้น

ภาพละเอียดประกอบด้วยมุมหลัก มุมหลัง ท่าก้มเตรียมพุ่ง และรายละเอียดวัสดุ ท่าพุ่งเป็นแนวทาง animation เท่านั้น การเพิ่มสกิลพุ่งจริงต้องออกแบบระยะ วงเตือน และ cooldown แยกจากงานภาพนี้

## แนวทางนำเข้าเกม

- ใช้ ID และช่วงเลเวลเดิม เพื่อเชื่อมตำแหน่งเกิด ชื่อ และของดรอปเดิมได้
- ผลิต sprite โปร่งใสแยกต่อชนิด ไม่ตัดภาพ concept ที่มีหลายมุมไปใช้เป็นเฟรมเดินโดยตรง
- ระบบเดิมรองรับ 8 ทิศ × 3 เฟรมเดินผ่าน `tools/build-monsters.js` และ `public/assets/monsters/index.json`; ควรสร้างและตรวจความต่อเนื่องของท่าทางก่อนนำเข้า
- คุมจุดยึดเท้าคงที่และขอบโปร่งใส ไม่ใส่เงาพื้นหรือกลุ่มแสงหนาจนบังวงโจมตี
- บอสต้องใหญ่กว่าหมูป่าปกติชัดเจน ตรวจสัดส่วนกับนักพรตและพื้นที่ลานบอสในเกมก่อนใช้งานจริง

## สไปรต์มอนสเตอร์ทั่วไปที่ใช้งานจริง

- ต้นฉบับโปร่งใสทั้ง 7 ไฟล์: `monster-art/village-v2/<id>-source.png`; ไฟล์ใช้ในเกม: `public/assets/monsters/<id>-v2.png` พร้อมข้อมูลเฟรมและเวอร์ชันแคชใน `index.json`.
- `npm run monsters:village` สร้างสไปรต์ทั้งชุด โดยรวมชิ้นส่วน alpha ของแต่ละท่าให้ครบ (รวมใบไม้และไข่มุกของภูตน้ำค้าง) จัดจุดเท้า และใช้สเกลเดียวกันตลอด animation ของแต่ละทิศ เก็บบอสและสไปรต์อื่นใน index ไว้.
- ขนาดภาพยืนอ้างอิง 176 pixels; ขนาดในโลกเกมใช้ `MON_ART.h × size` เดิม ไม่เพิ่ม hitbox หรือระยะโจมตี.
- `npm run check:monsters-village` ตรวจ 224 เฟรม ขอบโปร่งใส จุดยึด ความสูงท่ายืน เฟรมไม่ซ้ำ เวอร์ชันไฟล์ และชนิดมอนสเตอร์ครบตามแมพแรก.
- ทดสอบผ่านเกมจริงด้วย `node tools/preview-village.cjs 3904` และ Chromium CDP พอร์ต 9351 จากนั้น `npm run check:monsters-village-browser` ตรวจทิศ/ท่าครบ 224 เฟรม การกระพริบเมื่อถูกตี และการจางหาย โดยใช้ตัวละครจำลองกับเซิร์ฟเวอร์ preview ที่ไม่บันทึกข้อมูลผู้เล่น.
- ผลตรวจและภาพ: `artifacts/village-monsters-v2/check.json`, `lineup.png`, `in-game.png` และ `<id>-poses.png`. ผลล่าสุด: 224 เฟรมผ่าน, ไม่ใช้ภาพ procedural สำรอง, ไม่มีข้อผิดพลาด JavaScript หรือไฟล์โหลดไม่สำเร็จ.
- หน้า `art-preview.html` โหลดสไปรต์ชุดเดียวกับเกมแล้ว.

## โมเดลบอสที่ใช้งานจริง

- `npm run kingboar`: ตัด silhouette แบบรักษา alpha จาก `kingboar-south-source.png` และ `kingboar-north-source.png`; จัดจุดเท้าและ scale เดียวกันต่อทิศตลอด animation เป็น `public/assets/monsters/kingboar-v2.png` พร้อม metadata ใน `index.json`.
- ความสูงภาพยืน 132 world pixels ก่อน scale มอนสเตอร์ของ renderer; ทิศใน sheet คือ S, SE, E, NE, N, NW, W, SW. ท่าโจมตีใช้สัญญาณ melee เดิม ไม่เพิ่มสกิลพุ่งใหม่.
- `npm run check:kingboar`: ตรวจ 32 เฟรมไม่ซ้ำ ขอบโปร่งใส จุดเท้าคงที่ เลเวลและการผูกบอสแมพแรก.
- `npm run check:kingboar-browser -- http://127.0.0.1:3900 9351`: ตรวจ renderer ของเกมจริงผ่าน Chrome CDP ทั้ง 32 ท่า/ทิศ การตอบสนองเมื่อโดนตีและจางหาย และยืนยันว่าไม่ได้ใช้โมเดล procedural เดิม. ใช้ตัวละครจำลองที่ตัด socket ไม่เขียนบัญชีผู้เล่น.
- ภาพและผลตรวจ: `artifacts/kingboar-v2/kingboar-poses.png`, `kingboar-in-game.png`, `kingboar-attack.png`, `check.json`.
