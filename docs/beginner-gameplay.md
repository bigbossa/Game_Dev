# ช่วงเริ่มเกมสำหรับมือใหม่

ตัวละครทุกอาชีพ Lv.1–20 ได้แรงช่วยฝึกในหมู่บ้านเซียนน้อย ทั้งตัวละครใหม่และตัวละครเดิม โดยไม่เปลี่ยนค่าสถานะถาวร

| สิ่งที่ปรับ | Lv.1–10 |
|---|---|
| ความเสียหายต่อมอนสเตอร์ทั่วไป Lv.1–20 ในหมู่บ้าน | เพิ่ม 25% |
| ความเสียหายที่รับจากมอนสเตอร์กลุ่มนี้ | ลด 30% |
| EXP จากมอนสเตอร์กลุ่มนี้ | เพิ่ม 25% ต่อผู้รับ หลังคำนวณส่วนแบ่งปาร์ตี้ |
| พักเกิน 4 วินาทีโดยไม่โจมตี ร่ายสกิล หรือรับความเสียหาย | เพิ่มการฟื้น HP 2.8% และ MP 2.5% ของค่าสูงสุดต่อวินาที |

หลัง Lv.10 โบนัสทั้งหมดค่อย ๆ ลดลง: Lv.15 เหลือ 6/11 ของโบนัสเต็ม, Lv.20 เหลือ 1/11 และหมดที่ Lv.21 การฟื้นเดิมยังทำงานตามปกติ แรงช่วยพักฟื้นไม่ทำงานขณะตายหรือติดความเสียหายต่อเนื่อง

แรงช่วยไม่ทำงานนอกหมู่บ้าน ขณะเปิด PvP หรือยังติดสถานะต่อสู้ PvP และไม่เพิ่มดาเมจ/EXP หรือลดดาเมจในการสู้บอสหรือมอนสเตอร์เกิน Lv.20 ไม่มีการเปลี่ยน EXP ที่ GM ให้โดยตรง

ตัวละครที่สร้างใหม่ได้รับยาเลือดเล็ก 12 ขวด ยาปราณเล็ก 8 ขวด ใบกลับเมือง 2 ใบ และทอง 320 บันทึกพร้อมการสร้างตัวละคร การเข้าเกมซ้ำไม่เติมของหรือทองให้ใหม่ ตัวละครเดิมคงกระเป๋าและเงินเดิม

ข้อความต้อนรับและหน้าวิธีเล่นแนะนำให้เริ่มจากภูตน้ำค้าง Lv.1 ใช้ M หาเป้าหมายใกล้เลเวล ใช้ I เปิดกระเป๋า ใช้ K เรียนสกิล และ C แจกแต้ม ผู้เล่นยังเลือกเปิดการอัปสกิลและสถานะอัตโนมัติเองได้

ค่าปรับอยู่ที่ `BEGINNER` ใน `shared/common.js` ส่วนการใช้โบนัสอยู่ใน `server/world.js` ไม่มีการย้ายข้อมูลเซฟ

ตรวจด้วย `npm run check:beginner`: ใช้ combat, party EXP, join และ save จริงกับข้อมูลในหน่วยความจำ ครอบคลุม 6 อาชีพ 2 ฝ่าย การลดโบนัส การแยก PvP/บอส/แผนที่ การพักฟื้น และการไม่แจกของซ้ำ โดยไม่แตะบัญชีหรือฐานข้อมูลจริง
