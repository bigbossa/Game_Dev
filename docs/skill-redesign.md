# สกิลชุดใหม่: ดาบคู่ ทวน ธนู นักพรต

ออกแบบใหม่ครบ 44 สกิล (อาชีพละ 11 สกิล) โดยใช้แนวทางของมหาวิชา Lv.120/130: เตรียมท่า → เคลื่อนตัว/เหินตัว → ปล่อยวิชา → ปิดท่า → คืนตำแหน่ง แทนที่เอฟเฟกต์หลักของสี่อาชีพในเส้นทางที่เกมเรียกใช้จริง

## รูปแบบใหม่

| อาชีพ | เอกลักษณ์ |
| --- | --- |
| ดาบคู่ | คมพยัคฆ์ บัวเหล็ก ประตูเงา จันทร์คู่ กระบวนดาบเงา มังกรคู่ สุสานดาบ และดาบแยกฟ้า |
| ทวน | เกลียวทวน ยกภูผา เงาทวน ประตูพิพากษา บัวโลหิต พันธนาการ มังกรล่าเป้า เสาทวน และบัลลังก์มังกร |
| ธนู | เหยี่ยว พัดขนนก เนตรสุริยัน ก้าววายุ สวนศร ศรคราส กงล้อวายุ บุปผาอัคคี วิหคอสนี คลังศร และหงส์สุริยัน |
| นักพรต | พู่กันยันต์ อักษรอสนี บัวรักษา ประตูพิทักษ์ สะพานดารา กระบี่วิญญาณ ธงบัญชา ฝนดาว พฤกษานิพพาน ประตูแดนเซียน และอวตารหยินหยาง |

สกิลปกติ 36 ท่าใช้ keyframe เฉพาะตัวสำหรับการก้าวหน้า/ถอย เบี่ยงด้านข้าง ย่อ/เหิน ความเอียง การหันตัว และเฟรมอาวุธ สกิลระดับสูงอีก 8 ท่ามีเส้นทางใหม่ เช่น ก้าวดาบสลับฟันข้ามจุดเป้าหมาย เหินดาบลงจากฟ้า ค้ำทวนตีลังกา ยิงศรสลับตำแหน่งกลางอากาศ และร่ายยันต์ผ่านประตูสามทิศ

การเคลื่อนไหวใช้สไปรต์ตัวละครและอาวุธเดิมประกอบกับการขยับใน renderer ไม่ได้สร้าง atlas ตัวละครชุดใหม่ และไม่ย้ายตำแหน่งหรือเพิ่มระยะโจมตีบนเซิร์ฟเวอร์

## ความอลังการตามขั้น

- รายละเอียดเพิ่มตามแต้มสกิล 1–12 ขั้นวิวัฒนาการที่เรียนจริง และเลเวลปลดล็อกของวิชา
- ท่าเริ่มต้นใช้เส้นพลังและอาวุธกระชับ ขั้นกลางเพิ่มชั้นคม/ยันต์/ขนนกและความสูงของท่า ขั้นสูงเพิ่มเงาร่างและรูปทรงพลังที่ซับซ้อน
- Lv.120/130 ใช้เส้นทางเต็มรูปแบบและเอฟเฟกต์ปิดขนาดใหญ่ พร้อมประกายและแรงสั่นเมื่อเซิร์ฟเวอร์ยืนยันการปล่อยวิชา
- สีธรรมะ/อธรรมแยกกัน และชื่อกระบวนท่าใหม่ปรากฏในคัมภีร์สกิล โดยรหัสสกิล ปุ่ม แต้มสกิลเดิม และข้อมูลตัวละครยังใช้ต่อได้

## ความถูกต้องในการต่อสู้

ไม่มีการแก้ดาเมจ MP คูลดาวน์ จำนวนฮิต ระยะ หรือรูปทรงโจมตีบนเซิร์ฟเวอร์ในรอบนี้ การโจมตีหมู่ของทวนจากรอบก่อนยังทำงานตามเดิม

- ทวนแสดงรูปทรงกระแทกใหม่เมื่อได้รับ `spearBeat` จริงเท่านั้น และยังใช้เส้นขอบสกิลหมู่จากข้อมูลเซิร์ฟเวอร์
- การปิดวิชา 120/130 รอ `ritualRelease`; การยกเลิกจะล้างภาพทั้งท่าและผลปิดที่ยังไม่เกิด
- เริ่มสกิลใหม่จะเปลี่ยนท่าร่างกาย แต่ฝนศร/ค่ายกลที่ปล่อยแล้วแสดงต่อ การ stun ไม่ลบภาพสนามที่เซิร์ฟเวอร์ยังคงทำดาเมจ
- บัฟมีช่วงเปิดวิชาและสัญลักษณ์เล็กต่อเนื่องตามระยะเวลาที่เซิร์ฟเวอร์ส่งมา
- เอฟเฟกต์ใหม่จำกัด 144 ชิ้นพร้อมกัน callback วาดภาพไม่สร้าง timer หรือเพิ่มเอฟเฟกต์ใหม่ และคืนค่า Canvas ทุกครั้ง
- เปลี่ยนแมพ ตาย หรือยกเลิกท่าจะจัดการภาพตามวงจรชีวิตของสกิล
