# โมเดลดาบคู่ V2

เปลี่ยนภาพตัวละครทั้งตัวเป็นชุดที่วาดใหม่ ไม่ใช้ชุดเดิมหรือ mask เดิมในการเล่นจริง ภาพใหม่มีเสื้อปิดอก เกราะไหล่ ชายชุดแยก กางเกง ปลอกแขน และรองเท้าต่อเนื่องกัน ธรรมะใช้สีน้ำเงินเข้ม อธรรมใช้ดำแดง จึงอ่านรายละเอียดบนพื้นสีอ่อนได้

## ทรงผมและชุด

- Lv.1–39: ภาพผมสั้นและมวยเล็ก
- Lv.40–89: ภาพหางม้าระดับเอว
- Lv.90–130: ภาพหางม้ายาวแยกช่อ
- สีผมพัฒนาทุก 10 เลเวล ธรรมะไปทางเงินงาช้าง อธรรมไปทางดำแดง
- แต่ละช่องอุปกรณ์เปลี่ยนวัสดุและความกว้างของลายโลหะตามแนวชุดที่วาดไว้จริงในเฟรมนั้น ไม่มีแผงเกราะหรือชายชุดรูปทรงแยกซ้อนทับตัวละคร
- Lv.120: น้ำเงินเข้มขลิบเงิน / ดำม่วงขลิบอเมทิสต์
- Lv.130: น้ำเงินเข้มขลิบทอง / ดำแดงขลิบทองแดง

### รายละเอียดตามขั้นอุปกรณ์

| อุปกรณ์ | รูปลักษณ์ |
|---|---|
| ไม่สวม / Lv.5 | ผ้าโทนเข้ม ขลิบโลหะด้าน |
| Lv.15 | ผ้าหนังและโลหะสีบรอนซ์ |
| Lv.30–45 | ผิวโลหะเงินและขลิบสีฟ้า ลายเริ่มกว้างขึ้น |
| Lv.60–80 | ลายทองต่อเนื่องบนอก แขน ขา และไหล่ |
| Lv.100 | ลายทองกว้างขึ้นแต่ยังรักษารอยพับและเส้นขอบชุด |
| Lv.120 | ลายผลึกเงิน / อเมทิสต์บนพื้นชุดเข้ม |
| Lv.130 | ลายทอง / ทองแดงกว้างที่สุดตามพื้นผิวเกราะจริง |

วัสดุอุปกรณ์อิง `ar` แยกทั้งสี่ช่อง การเพิ่มเลเวลตัวละครอย่างเดียวไม่เปลี่ยนชุดที่สวมอยู่ ชุดผสมต่างขั้นยังแสดงเฉพาะชิ้นที่เปลี่ยน รูปผมและสีผิวเดิมอยู่ในชั้นภาพเดิม

ภาพผมทั้งสามแบบมีท่ายืน เดินซ้าย เดินขวา และฟันดาบในห้าทิศต้นฉบับ ขยายเป็นแปดทิศด้วยการสะท้อนภาพ จุดเท้าและขนาดใช้สเกลเดียวกัน ท่าโจมตีลดความสูงด้วยการย่อตัวตามภาพต้นฉบับ ไม่ย่อทั้งศีรษะ ตัวละครจับดาบใหม่จากจุดมือเฉพาะแต่ละเฟรม

## ไฟล์และการประกอบ

- ต้นฉบับ: `class-art/dualblade-v2/{short,medium,long}-source.png`
- คำสั่งสร้างภาพด้วย built-in imagegen: `class-art/dualblade-v2/PROMPTS.md`
- แพ็กภาพ: `npm run dualblade` → `public/assets/dualblade-v2/`
- โหลด / ย้อมผิวชุด / ทรงผม / รูปโปรไฟล์: `public/js/dualblade-model.js`
- วัสดุชุดแต่ละขั้น: `public/js/dualblade-armor.js` คำนวณระยะจากแนวโลหะที่วาดอยู่จริงภายในแต่ละชิ้นและเฟรม แล้วขยายลายภายในพื้นผิวชุด เก็บผลใน cache ไม่อ่านพิกเซลซ้ำทุกเฟรม
- ออร่าและปีกหนึ่งคู่: `public/js/dualblade-look.js`
- จุดแสงอุปกรณ์เลือกเฉพาะพิกเซลทึบของอุปกรณ์ใหม่ตามท่าและทรงผม
- โหลดภาพใหม่โดยตรงใน `main.js` ไม่โหลดภาพร่างเก่าหรือชุด mask เก่าของดาบคู่

การแพ็กตัดเศษจากช่องข้างเคียงด้วย connected components และกำหนดจุดศีรษะ คอ เท้า และมือจากภาพที่ตรวจแล้ว ตัวประกอบชุดรักษา alpha ของต้นฉบับทุกพิกเซล และคัดลอกสีหน้า ผิว มือ และผมที่ได้รับการป้องกันตรงตามเดิม ไม่ใช้พิกัดศีรษะคำนวณแผ่นอก ไม่สร้างไหล่หรือชายชุดแยกออกจากกรอบตัวละคร และไม่ระบายทับขอบผมด้วย source-over ซ้ำ ดาบยังเปลี่ยนตามอาวุธที่สวม

## ตรวจสอบ

เปิดเซิร์ฟเวอร์ทดสอบแยกบนพอร์ต 3901 กับ Edge CDP 9334 แล้วใช้ `npm run check:dualblade-browser` หรือ `node tools/check-dualblade-design.cjs` (ชื่อเก่าเรียกตัวตรวจ V2)

ตรวจ 56 แบบสี/เลเวล, 1,344 กรณีท่าและทิศ, alpha ตรงต้นฉบับทุกพิกเซล, ไม่มีสีชุดอยู่นอกตัวละคร, สีผิว, cache, การเปลี่ยนอุปกรณ์แยก 4 ช่อง รวม 32 กรณี, จุดแสงอุปกรณ์ และไม่มีปีกด้านหน้าบังตัวละคร ชุดแต่ละขั้นต้องมีวัสดุต่างกันในขณะที่กรอบตัวละครเดิมคงที่

ภาพตรวจ: `artifacts/dualblade-v2-gallery.png`, `dualblade-v2-directions.png` และ `dualblade-v2-world.png` (ขนาดโลกจริงบนพื้นสีอ่อน)

`artifacts/dualblade-v2-comparison.png` เทียบชุดทุกขั้นโดยล็อกทรงผมและซ่อนปีก/อาวุธ/ออร่า มีทั้งขนาดหน้าต่างตัวละครและขนาดโลกจริง เพื่อให้เห็นความต่างจากตัวชุดเอง

`artifacts/dualblade-fit-motion.html` เล่นภาพจากตัวแสดงผลเกมจริงแบบออฟไลน์ ทั้งธรรมะและอธรรม เลือกยืน/เดิน/โจมตี หมุนแปดทิศ และสลับขนาดโลกจริงได้ ใช้ไฟล์ `dualblade-fit-motion-{dharma,adharma}.png` ในโฟลเดอร์เดียวกัน
