# นักพรต v2

โมเดลนักพรตแบบ chibi วาดลงสีให้เข้ากับอาชีพนักรบ: ธรรมะชุดขาว–ฟ้า–ทอง อธรรมชุดดำ–แดง–ทอง ใช้แส้ ยันต์ เครื่องหมายหยินหยาง และน้ำเต้าเป็นเอกลักษณ์

- ต้นฉบับและ prompt: `class-art/taoist-v2/` (สร้างด้วย built-in image_gen)
- ไฟล์ใช้ในเกม: `public/assets/taoist-v2/`
- ภาพพรีวิว: `artifacts/taoist-v2/taoist-v2-preview.png`
- แผ่นภาพแปดทิศ: 4 เฟรมเดิน และ 3 เฟรมร่ายต่อฝ่าย รวม 112 เฟรม
- ทิศ NW / W / SW ใช้ภาพกลับด้านจาก NE / E / SE ตามรูปแบบอาชีพอื่น
- หน้าเลือกตัวละครใช้ portrait จากภาพต้นฉบับความละเอียดเต็ม
- `rig.json` เก็บขอบเขตภาพและจุดยึดคอ/แส้เพื่อให้เครื่องแต่งกายตรงกับท่าใหม่
- โมเดลใหม่มีสัดส่วน chibi อยู่แล้ว จึงข้ามการบิดสัดส่วนท่าร่ายของรุ่นเดิม
- การเปลี่ยนสีผมตามระดับผสมกับสีเดิม และลดแสงฟุ้งเพื่อรักษารายละเอียดเส้นผม

## สร้างและตรวจ

```sh
npm run taoist
npm run check:taoist
```

ตรวจในเบราว์เซอร์ด้วย `npm run check:taoist-browser`: ต้องมี Chrome สำหรับทดสอบแยกที่ CDP port 9347 และ preview server ที่ `http://127.0.0.1:3902` (ใช้ `node tools/preview-warrior.cjs` ซึ่งอ่านไฟล์ปัจจุบันและดึงเฉพาะแผนที่จากเกม port 3900)

ผลตรวจ: 112 เฟรมผ่านการตรวจขนาด พื้นโปร่งใส ขอบภาพ ระดับเท้า mask และจุดยึด; เบราว์เซอร์ตรวจท่า 96 แบบ ชุด 14 แบบ แส้ 22 แบบ ภาพเลือกฝ่าย การเดิน/หยุด และแคช ไม่มี runtime error

ไฟล์เก่าเก็บไว้ และสร้างซ้ำได้ด้วย `npm run taoist:legacy` แต่เกมโหลด v2 โดยตรง การเปลี่ยนนี้อยู่ใน workspace; container เกมที่ build ไว้ก่อนหน้านี้ต้อง rebuild จึงจะได้รับไฟล์ใหม่
