# ธรรมะ ⚔ อธรรม Online

2D MMORPG บนเบราว์เซอร์ (Node.js + Socket.IO + Canvas) สองฝ่าย ธรรมะ (ชุดขาวฟ้า) และ อธรรม (ชุดดำแดง)

แผนที่ล่ามอนสเตอร์ Lv.1–130 ใช้ร่วมกันทั้งสองฝ่าย (ไม่มี PvP) · ฝ่ายมีผลเฉพาะใน **สนามรบธรรมะ-อธรรม** (แผนที่ PvP แยก)

## รันเกม

```bash
npm install
copy .env.example .env   # ใส่รหัสผ่าน PostgreSQL ใน DATABASE_URL
npm start                # http://localhost:3900  (เปลี่ยนพอร์ตด้วย PORT=xxxx)
npm run gm -- <บัญชี>    # ตั้งบัญชีเป็น GM (ต่อท้าย off = ยกเลิก) แล้วผู้เล่นกด F5
```

เปิดหลายแท็บ/หลายเครื่องเพื่อเล่นร่วมกัน

### ฐานข้อมูลและการเข้าสู่ระบบ

- ข้อมูลอยู่ใน **PostgreSQL** (`DATABASE_URL` ใน `.env` · ฐานข้อมูลสร้างให้เองตอนเปิดครั้งแรก): ตาราง `accounts` (บัญชี รหัสผ่านแบบ scrypt hash · `is_gm`) · `sessions` (โทเคนจำการเข้าสู่ระบบ 30 วัน เก็บเฉพาะ sha256) · `characters` (คอลัมน์ name / account_id / faction / cls / lvl + เซฟทั้งก้อนใน `data` JSONB) · `meta`
- ตัวละครอยู่ในหน่วยความจำและเขียนลงฐานข้อมูลทุก 20 วินาที ตอนผู้เล่นออก และตอนปิดเซิร์ฟเวอร์ (Ctrl+C) (`server/store.js`)
- หน้าแรก: **เข้าสู่ระบบ / สมัครบัญชี** → **เลือกตัวละคร** (บัญชีละไม่เกิน `MAX_CHARS` = 6 ตัว) → **สร้างตัวละครใหม่** (เลือกฝ่าย อาชีพ ชื่อ) · รีเฟรชแล้วไม่ต้องใส่รหัสใหม่ · เปลี่ยนรหัสผ่านได้ในหน้าเลือกตัวละคร (อุปกรณ์อื่นถูกออกจากระบบ) · ใส่รหัสผิด 10 ครั้งใน 10 นาที = ล็อก IP นั้น 10 นาที
- **ตัวละครเดิมจาก `data/players.json`** ถูกนำเข้าครั้งเดียวตอนเปิดครั้งแรก โดยยังไม่มีเจ้าของ: สมัครบัญชีด้วยชื่อเดียวกับตัวละคร = ได้ตัวนั้นทันที หรือพิมพ์ชื่อในช่อง **ผูกเข้าบัญชี** หน้าเลือกตัวละคร · ใครผูกก่อนได้ก่อน
- โค้ด: `server/db.js` (เชื่อมต่อ สร้างตาราง นำเข้า JSON) · `server/accounts.js` (สมัคร/เข้าสู่ระบบ/โทเคน) · `World.onAuth` / `onClaim` / `join` ใน `server/world.js` · `initLogin` ใน `public/js/main.js`

เพิ่มอาวุธและชุด 4 ชิ้น **Lv.120 / 130** ครบทุกอาชีพ ทั้งธรรมะและอธรรม พร้อมสกิลหมู่อาชีพละ 2 สกิล ไม่ต้องยืนร่าย แต่ละอาชีพมีท่าเคลื่อนที่ของตัวเอง (ดาวห้าแฉก/เทพจุติ · ฝนศรกลุ่มดาว/หงส์จักรวาล · ค่ายกลยันต์/มหามณฑล · ค้ำทวนกระโดด/ทวนมังกรเกลียว) ใช้ช่องลัด **0 / -** เรียนใน K อุปกรณ์ซื้อได้ที่ช่างตีดาบและดรอปตามระดับมอนสเตอร์ ดู [ดีไซน์ ค่าสกิล และการทดสอบ](docs/ascended-equipment-skills.md) · ซูมออกด้วย Shift + - หรือเลื่อนเมาส์

อาชีพ **ทวน (Spearman)** ใช้ต้นแบบจาก `modelทวน/` ออกแบบสไปรต์ใหม่ใน `class-art/spearman-v2/` ทั้งธรรมะและอธรรม มีท่ายืน เดิน และแทง 8 ทิศพร้อมทวนที่จับอยู่ในมือ เปลี่ยนรูปลักษณ์ตามช่วงเลเวลใน `models` และอุปกรณ์ที่สวม เอฟเฟกต์ทั้ง 9 สกิลเพิ่มรายละเอียดทุก 10 เลเวล โจมตีประชิดเป้าเดียว มี ATK/HP/MP สูง แต่เกราะและคริติคอลต่ำ ดู [รายละเอียดสกิลทวนและการสร้างสไปรต์](docs/spearman.md)

## สร้างสไปรต์ใหม่

ถ้าแก้ `model.png` (ธรรมะ เดิน 8 ทิศ × 3 เฟรม), `แผ่นออกแบบตัวละครฝ่ายอธรรม.png` (อธรรม เดิน 8 ทิศ × 3 เฟรม + ภาพหน้าตรง เลย์เอาต์เดียวกับ `model.png`),
`model-2.png` (โจมตี 8 ทิศ × 3 เฟรม) หรือ `item.png` (อาวุธ 10 ระดับ):

```bash
npm run sprites
```

สคริปต์ `tools/build-sprites.js` จะตัดพื้นหลังขาว แยกเฟรม ย่อขนาดท่าโจมตีให้เท่าท่าเดิน
ท่าเดินและภาพหน้าตรงของอธรรมตัดจากแผ่นออกแบบของอธรรมเอง (ถ้าไม่มีไฟล์นี้ จะเปลี่ยนสีจากชุดธรรมะเป็นดำแดงแทน)
ท่าโจมตีของอธรรมยังเปลี่ยนสีจาก `model-2.png` (ยังไม่มีแผ่นออกแบบท่าโจมตีของอธรรม) พร้อมเลเยอร์ใบดาบ (`blade-*.png`) ที่ใช้เปลี่ยนสีดาบตามอาวุธ
`tools/item-icons.js` ตัดไอคอนจาก `item.png` (ใช้เป็นภาพอ้างอิงเท่านั้น เกมวาดไอคอนเองด้วย `public/js/item-art.js`)
`tools/armor-masks.js` สร้างมาสก์ชุด `armor-*.png` (R = เสื้อ, G = กางเกง, B = ปลอกแขน) และ `armor2-*.png` (R = หัวไหล่) ที่ใช้เปลี่ยนสีชุดตามเกราะที่สวม
(ท่าเดินอธรรมมีมาสก์ของตัวเอง `armor-walk-adharma.png`: ผ้าแดง = ผ้าสีเด่น, ชุดดำ = แตะสีเบาๆ, ผมไม่เปลี่ยน)
(`MASK_PREVIEW_DIR=โฟลเดอร์ node tools/armor-masks.js --preview` สร้างภาพตรวจสอบสีแยกส่วน)
`tools/weapon-sprites.js` หาตำแหน่งดาบในทุกเฟรม (ท่าเดินตรวจจับอัตโนมัติแยกฝ่าย `walk` / `walkAdharma` · ท่าโจมตีกำหนดเองใน `tools/attack-blades.json`) เป็น `weapons.json`
และสร้างสไปรต์ไม่มีดาบ `*-bare.png` เกมจึงวาดดาบของไอเทมที่สวมอยู่ (ภาพเวกเตอร์คมชัด) ลงในมือแทนดาบเดิม
(`WEAPON_PREVIEW_DIR=โฟลเดอร์ node tools/weapon-sprites.js --preview` สร้างภาพตรวจสอบตำแหน่ง)
ถ้าเปลี่ยน `model-2.png` ต้องแก้ตำแหน่งด้ามและปลายดาบใน `attack-blades.json` ใหม่ ผลลัพธ์อยู่ที่ `public/assets/`

ท่าโจมตีใน `model-2.png` วาดซ้อนกัน จึงแยกด้วยจุดเริ่มต้น (seed) ที่กำหนดไว้ใน `tools/attack-frames.js`
ถ้าเปลี่ยนรูปต้องปรับพิกัด seed ใหม่

## อาชีพนักธนู (Archer)

เลือกได้ในหน้าเข้าเกม (🏹 นักธนู) · ใช้ระบบเดียวกับอาชีพอื่น: แต้มสกิล/สเต็ก/อัพขั้น (K), แต้มสถานะ (C), ชุดและอาวุธช่องเดิม (นักธนูเห็นอาวุธเป็น **ธนู** ทั้งชื่อและไอคอน)

- **สไปรต์**: วางภาพจาก AI ไว้ใน `modelนักธนู/` แล้วสั่ง `npm run archer` (`tools/build-archer.js`) → `public/assets/archer-<ฝ่าย>.png` (เดิน + ยืน), `archer-<ฝ่าย>-attack.png` (ท่ายิง), `archer-<ฝ่าย>-portrait.png` และ `archer.json`
  - `model <ชื่อ>.png`: เทมเพลตเดียวกับ model.png (Turnaround 8 ทิศ + Walk Cycle 8 ทิศ x 3 เฟรม) · ชื่อไฟล์มีคำว่า "อธรรม" = ฝ่ายอธรรม
  - `attack<ชื่อ>.png`: Attack Cycle 4 x 2 แผง แผงละ 3 เฟรมที่วาดซ้อนกัน → ตัดแยกด้วยเส้นตัดที่ผ่านลายเส้นน้อยที่สุด · แผงฝั่งซ้าย (หลัง-ซ้าย ซ้าย หน้า-ซ้าย) ใช้ฝั่งขวากลับด้าน เพราะ AI วาดตำแหน่งตัวละครในแผงซ้ายเพี้ยน
  - ทิศ / เฟรมที่ตัดไม่สวย แก้ได้ใน `modelนักธนู/directions.json` แล้ว `npm run archer` (ตัวอย่าง: ธรรมะหันหน้า ใช้ท่าง้างสุดแทนท่าปล่อยศร)
- **สกิล** (ยิงไกล · บัพคริ · บัพตีไว · ยิงหมู่บางสกิล): 1 ศรเหยี่ยว · 2 ศรพิรุณกระจาย · 3 เนตรเหยี่ยว (บัพคริ) · 4 ลมกรดเร่งศร (บัพตีไว) · 5 ฝนศรพันดอก · 6 ศรเจาะหัวใจ · 7 ม้วนเงาลม · 8 ศรระเบิดอัคนี · 9 หงส์อสนีทะลวงฟ้า — รายละเอียดใน [docs/class-skills.md](docs/class-skills.md)
- **ลักษณะตามเลเวล** ใช้ชุดเดียวกับนักพรต (ผมคงทรงเดิม เปลี่ยนสีตามเลเวล มงกุฎ ปีก รัศมี) · **ชุดเกราะ** ให้ค่าพลังแต่ยังไม่เปลี่ยนสีชุดบนตัวนักธนู (ยังไม่มีมาสก์ชุด)

## อาชีพนักพรต (Taoist)

เลือกได้ในหน้าเข้าเกม (🔮 นักพรต) · ตัวละครที่สร้างไว้แล้วใช้อาชีพเดิมเสมอ (อาชีพเก็บใน `data/players.json` ช่อง `cls`)

- **สไปรต์**: วางภาพจาก AI ไว้ใน `modelนักพรต/` แล้วสั่ง `npm run taoist` (`tools/build-taoist.js`) → `public/assets/taoist-<ฝ่าย>.png` (เดิน), `taoist-<ฝ่าย>-attack.png` (ร่ายเวท), `taoist-<ฝ่าย>-portrait.png`, `items/taoist-w1..w10[-a].png` (ไอคอนแส้) และ `taoist.json`
  - **ไฟล์หลัก `model dharma.png` / `model adharma.png`** (เลย์เอาต์เดียวกับ `model.png` ของดาบคู่): แถวบน 8 ทิศ = ท่ายืน · ตาราง Walk Cycle 8 ทิศ × 3 เฟรม = ท่าเดิน · ภาพหน้าตรง = รูปหน้าตัวละคร (ไฟล์ walk / design เก่าใช้เฉพาะฝ่ายที่ยังไม่มีไฟล์ model)
  - ไฟล์ `*walk*.png`: ธรรมะครึ่งซ้าย อธรรมครึ่งขวา 7 คอลัมน์ (หน้า หน้า-ขวา ขวา หลัง-ขวา หลัง ซ้าย หน้า-ซ้าย · หลัง-ซ้ายใช้หลัง-ขวากลับด้าน) × 4 แถว (ยืน + เดิน 3 เฟรม)
  - ไฟล์ `*cast*.png`: ฝ่ายละไฟล์ 8 ทิศ × 3 แถว (ประสานมือ · ชูแส้ · ผลักฝ่ามือ) · ไฟล์ `*weapons*.png`: แส้ 10 ระดับ 5 × 2
  - ไฟล์ `taoist-<ฝ่าย>-design.png`: ภาพเต็มตัว หน้า · ข้าง (หันขวา) · หลัง → **ท่ายืนนิ่ง** (แถวที่ 4 ของชีตเดิน; ทิศเฉียงใช้มุมที่ใกล้สุด ซ้าย = ข้างกลับด้าน) และ **รูปหน้าตัวละคร**
  - สคริปต์ดูฝ่ายจากสีชุด (ดำแดง = อธรรม) ไม่ได้ดูจากชื่อไฟล์ · หาช่องเองจากแนวที่ว่าง แล้วย่อให้สูงเท่าตัวละครดาบคู่
  - **ทิศของแต่ละคอลัมน์** ตั้งใน `modelนักพรต/directions.json` (AI วาดเรียงทิศไม่ตรงที่สั่งเสมอ) · `m3` = ใช้คอลัมน์ 3 กลับด้าน · ถ้าเดินเฉียงแล้วหันผิดทาง แก้ไฟล์นี้แล้ว `npm run taoist`
  - prompt สำหรับสร้างภาพเพิ่ม: `class-art/taoist/PROMPTS.md`

  ท่าประจำขั้นทุก 10 เลเวล: ธรรมะ = แสงรักษา (กากบาทแสง ใบไม้) วงกลีบบัว เสาแสงหยก · อธรรม = ประกายไฟ วงหนามแตก เปลวมืด · **ชุดเกราะ** ให้ค่าพลังแต่ยังไม่เปลี่ยนสีชุดบนตัวนักพรต
- **อาวุธ** ใช้ไอเทมช่องอาวุธเดิม (ค่าพลังเท่ากัน) แต่นักพรตเห็นเป็น **แส้** ทั้งชื่อและไอคอน (`C.setViewClass`)
- **ชุดนักพรต**: ไอเทมชุดเดิม (ค่าพลังเท่ากัน) แต่นักพรตเห็นเป็นชุดสายเต๋า — ชื่อ (ชุดคลุม / กางเกง / ผ้าพันข้อมือ / ผ้าคลุมไหล่ + ชุดผ้าฝ้ายศิษย์เต๋า · ไหมเมฆา · ยันต์คุ้มกาย · ไหมวายุ · หยกมรกต · บัวทองโอสถ · เซียนสวรรค์), ไอคอน (`TAO_ICON` ใน `item-art.js`) และชิ้นบนตัว (`CLS` ใน `armor-look.js`): ลายเมฆเย็บ ลายตรีแกรม ลายบัวทอง ผ้าพันแข้งติดยันต์/คาดหยก แขนเสื้อติดยันต์/ลูกปัดหยก ผ้าคลุมไหล่รูปเมฆ จานยันต์แปดทิศ/ไท่จี๋ทองที่เอว ตราไท่จี๋บนอก — ไม่มีเกราะเหล็ก เกล็ด หรือเขามังกร
  - **ผ้าคลุมไหล่** (`taoShawl` ใน `armor-look.js`): ผ้าคลุมไหล่ตัดจากผ้าชุดคลุม (สีผ้า + ลายของชุด + ขลิบสีชุด) ขอบหยักรูปเมฆ วางที่แนวคาง ~55% ของความสูงตัว (ดาบคู่ใช้ 47%) · มุมหลังเว้นตรงกลางให้เห็นผม/ริบบิ้น · ยันต์ห้อย (ชุด 3) พู่ (4, 6+) ตะขอหยก+ลูกปัด (5) ตะขอบัวทอง (6) กลีบแสงลอย (7)
  - **เอฟเฟกต์ชุดและอาวุธโทนนักพรต**: แสงขอบตัวตามระดับไอเทม ธรรมะ เขียวหยก→ทอง · อธรรม แดงเพลิง→เลือด (`AL.lightOf`) · ผ้าคล้องแขนเทพ (ชุด 7) ปลายบัว / ปลายขาดเป็นเศษ · วงเวทใต้เท้าตามระดับอาวุธ: ธรรมะ = มณฑลบัวแปดทิศรอบไท่จี๋ · อธรรม = ตรามารดาวห้าแฉกแตกร้าวมีหนาม (`taoSigil`) · ออร่า ประกาย และสีเวทใช้โทนเดียวกัน (`TAO_WL` ใน `weapon-look.js`)
- **เอฟเฟกต์ชุดและอาวุธเหมือนดาบคู่**: ชุดเกราะเปลี่ยนสี/ลายเสื้อ กางเกง แขนเสื้อ และวาดหัวไหล่ เข็มขัด ผ้าห้อยตามชุด (มาสก์ `armor-tao-<ท่า>-<ฝ่าย>.png` จาก `npm run taoist`, `ArmorLook.sheet(..., 'taoist')`) · แสงขอบตัวตามระดับไอเทม · วงเวทใต้เท้าและออร่าหลังตัวตามระดับอาวุธ · ประกายอาวุธและเอฟเฟกต์ตีบวก +N ออกจากแส้/ปลายแขนเสื้อ (`weaponPts` ใน `taoist.json`) · สีเวทตามสีอาวุธ
  - ข้อจำกัด: รูปทรงแส้ในมือยังเป็นแส้ที่วาดในสไปรต์ (ดาบคู่ใช้สไปรต์ไม่มีดาบแล้ววาดดาบของไอเทมลงมือ) — ถ้าต้องการให้แส้ในมือเปลี่ยนตามระดับ ต้องมีชีตนักพรตแบบไม่ถือแส้
- **สกิล** (เวทระยะไกล · ฮีลหมู่ · บัพตัวเองและปาร์ตี้): 1 ยันต์หยกพิฆาต · 2 อสนีเมฆา · 3 น้ำทิพย์ชโลมชีวา (ฮีลหมู่) · 4 ยันต์เกราะห้าธาตุ (บัพเกราะ) · 5 ค่ายกลสวรรค์ (ดาเมจ + ฮีลในวง) · 6 กระบี่วิญญาณเหิน · 7 ยันต์ปลุกเทพยุทธ์ (บัพดาเมจ) · 8 ดาวตกเพลิงฟ้า · 9 พรสวรรค์ชุบชีวา (ฮีลหมู่ใหญ่ + ล้างสถานะ) — ตารางเต็มใน [docs/class-skills.md](docs/class-skills.md)

- กล่องบอทใช้สกิลของอาชีพตัวเอง (ฮีลใช้เมื่อตัวเองหรือสมาชิกปาร์ตี้เลือดลด · บัพใช้ทันทีที่คูลดาวน์หมด) · ปุ่มสกิลบนมือถือวางตามเลขปุ่ม (`data-key`) จึงใช้ได้ทุกอาชีพ

## วิชาดาบคู่ทุก 10 เลเวล (สกิล ท่าทาง เอฟเฟกต์)

ทุก 10 เลเวลได้สกิลใหม่หรือ "พัฒนา" สกิลเดิม (เปลี่ยนชื่อ ท่า เอฟเฟกต์ และแรงขึ้น 30% ต่อขั้น · ★ บนปุ่มสกิล) ข้อมูลอยู่ใน `skills[].evo` ของ `shared/common.js` (`C.SKILL_STAGES`)

สกิลดาบคู่เน้นโจมตีระยะประชิดทั้งหมด และตีหมู่ได้บางสกิล: 1 เขี้ยวคู่พยัคฆ์ · 2 ระบำบัวเหล็ก (ตีหมู่รอบตัว) · 3 ก้าวเงาสังหาร (วาบหลังเป้า) · 4 ฉีกเกราะกากบาท (เกราะแตก) · 5 พายุพันคม (ตีหมู่รอบตัว เดินได้) · 6 จันทร์เสี้ยวผ่าปฐพี (ตีหมู่หน้ากว้าง) · 7 พยัคฆ์ร่วงฟ้า · 8 พันคมไร้เงา (ฟันรัวเป้าเดียว) · 9 มังกรคู่ผ่าสวรรค์ — เลเวล ผล และขั้นวิวัฒนาการอยู่ใน [docs/class-skills.md](docs/class-skills.md)

- **ยิ่งเลเวลสูงเอฟเฟกต์ยิ่งอลังการ:** ทุกสกิลใช้ "ขั้นเอฟเฟกต์" = ค่าสูงกว่าระหว่างระดับอาวุธ กับขั้นวิชา × 0.8 (Lv.130 = เอฟเฟกต์ขั้น 10 เต็ม) ขนาดใหญ่ขึ้น 3% และประกายเพิ่มทุกขั้น (`powerFor` ใน `fx.js`)
- **ท่าประจำขั้น:** ลมปราณลอยขึ้นจากเท้า (มากขึ้นทุกขั้น) → Lv.20 วงปราณใต้เท้า → 60 วงเวทใต้ร่าง → 80 ปราณเพลิงที่เท้า → 90 วงเวทซ้อน · ไม่มีเอฟเฟคหมุนรอบตัวละคร · ปีก วงแหวน และเขามาจากลักษณะตามเลเวล (`drawStance` ใน `main.js`, `wings.js`, `model-tiers.js`)
- **ท่าทางตอนใช้สกิล:** กระโดดเป็นวิถีโค้ง (เงาเล็กลงตอนลอย) · เดินได้ระหว่างพายุพันคม · ตัวสั่นรัวตอนพันคมไร้เงา · พุ่งแทงตอนมังกรคู่/จันทร์เสี้ยว · หมุนตัวตอนฟันครั้งที่ 3 (`poseOf`)
- **คูลดาวน์:** ทุกสกิลมีคูลดาวน์ของตัวเอง (5–31 วิ · ค่าใน `skills[].cd` × `C.SKILL_CD_MUL` 1.3) + คูลดาวน์ร่วม 0.7 วิ ระหว่างสกิล 2–9 (`C.GCD_MS`) แสดงเป็นวงหมุนและตัวเลขบนปุ่ม (ต่ำกว่า 1 วิแสดงทศนิยม)
- **ปราณที่ใช้ตามเลเวล:** สกิลใช้ปราณ = ค่าที่เขียนไว้ (`sk.mp`) หรือ `sk.mp × 0.35%` ของปราณพื้นฐานอาชีพที่เลเวลนั้น (สูงสุด 45%) แล้วแต่ค่าไหนมากกว่า (`C.skillMp`) · ปราณจากอุปกรณ์/แต้มสถานะไม่นับ จึงยังช่วยให้ใช้สกิลได้นานขึ้น · โจมตีปกติไม่ใช้ปราณ · ตัวเลขบนปุ่มสกิลและคัมภีร์อัปเดตตามเลเวล
- **โจมตีธรรมดาโดนทีละ 1 ตัว:** เป้าที่ล็อกไว้ ถ้าไม่มีจะเลือกตัวที่ใกล้ที่สุดด้านหน้า (`slashTarget` ใน `world.js`)

มือถือแนวตั้ง (กว้าง ≤ 600px): กรอบตัวละครย่อเหลือ 60% มุมซ้ายบน · แชทใต้กรอบตัวละครแสดง 2 บรรทัดล่าสุด (กด 💬 เปิดเต็มใต้มินิแมป) · มินิแมปเล็ก มุมขวาบน · ปุ่มกลมเรียงแนวตั้งใต้มินิแมป · ปุ่มสกิลและจอยย่อลง (จอ ≤ 380px ย่อเพิ่ม) — ปรับได้ใน `@media (orientation: portrait)` ท้าย `style.css`

## กล่องบอท (ล่าอัตโนมัติ)

กด **O** หรือปุ่ม 🤖 เปิดหน้าต่าง ตั้งค่าแล้วกด **เริ่มบอท** — จุดที่ยืนอยู่ตอนเริ่มคือศูนย์กลาง (วงประสีเขียวบนพื้น)

- **รัศมีล่า** 150–1200: บอทเลือกเฉพาะมอนสเตอร์ในวง (ตัวที่กำลังตีเราก่อน แล้วตัวที่ใกล้ที่สุด) ไม่มีมอนสเตอร์จะเดินกลับจุดเริ่ม
- **โจมตีปกติ** (เดินเข้าไปฟันทีละตัว) และ/หรือ **สกิลที่ติ๊ก** (ใช้เมื่อพร้อม ปราณพอ และเป้าอยู่ในระยะ ลำดับจากสกิลใหญ่ก่อน) · ปิดโจมตีปกติ = เดินเข้าระยะสกิลแล้วยืนร่าย
- **เติมยาเลือด / ยามานา** เมื่อต่ำกว่า % ที่ตั้ง (10–90%) ทำงานแม้กำลังควบคุมเอง
- กด WASD / จอย / คลิกพื้น = ควบคุมเองชั่วคราว แล้วบอททำต่อ · หยุดเองเมื่อตายหรือเปลี่ยนแผนที่ · กดป้ายสถานะเหนือแถบสกิลเพื่อหยุด
- ค่าที่ตั้งจำไว้ในเบราว์เซอร์ (`public/js/bot.js`)

## ระบบ

- แผนที่ล่ามอนสเตอร์: ทั้งสองฝ่ายอยู่ด้วยกัน โจมตีกันไม่ได้ · EXP แบ่งกันเฉพาะในปาร์ตี้
- **แผนที่ใหญ่** (กด **M** หรือคลิกมินิแมป): แสดงถิ่นมอนสเตอร์ทุกจุดพร้อมชื่อและเลเวล สีตามความเหมาะกับเลเวลตัวละคร (เขียว = พอดี · ส้ม = สูงกว่า · แดง = อันตราย · เทา = ต่ำไป EXP ลด) ค่ายพัก ประตู บอส สมาชิกปาร์ตี้ · คลิกป้าย/รายการ/จุดใดก็ได้ = เดินไปอัตโนมัติ (`public/js/worldmap.js`, `G.travelTo`)
- **คู่มือดรอป** (ปุ่ม **✦ คู่มือดรอป** ในแผนที่ใหญ่): ทุกแผนที่ ทุกมอนสเตอร์ ดรอปอาวุธ / ชุด Lv. เท่าไหร่ โอกาสต่อการฆ่า 1 ตัว (บอส = โอกาสเป็นชิ้นนั้นของที่ได้แน่นอน) ทองที่ได้ และป้าย **Epic+** เมื่อลุ้นเกรด Epic ขึ้นไปได้ · เลือก "หาไอเทม Lv." เพื่อดูว่าไอเทมเลเวลนั้นได้จากมอนตัวไหน · คลิกมอนในแผนที่ปัจจุบัน = เดินไปหา (ข้อมูลจาก `C.dropGuide` ใน `world-data.js`)
- **ปาร์ตี้** (`public/js/party.js`, `server/world.js`): ชวนได้ทั้งฝ่ายเดียวกันและต่างฝ่าย สูงสุด 8 คน · **เข้าปาร์ตี้ต้องให้อีกฝ่ายกดยินยอม**: ผู้ถูกชวนเห็นป๊อปอัป (รูป ชื่อ เลเวล อาชีพ ฝ่าย จำนวนคนในปาร์ตี้ นับถอยหลัง 30 วิ) กด **ตกลง (Y)** หรือ **ปฏิเสธ (N)** · ไม่ตอบภายในเวลา = ปฏิเสธ คนชวนได้รับแจ้ง · หลายคำเชิญเข้าคิวทีละอัน · ชวนซ้ำระหว่างรอตอบไม่ได้ · คลิกผู้เล่น → ชวนเข้าปาร์ตี้ (ในสนามรบ PvP คลิกศัตรู = เลือกเป้า ให้ใช้ `/party ชื่อ` แทน) หรือ `/party ชื่อ` · `/p ข้อความ` แชทปาร์ตี้ · `/leave` ออก · `/kick ชื่อ` (หัวหน้า) · หัวหน้าออก = คนถัดไปเป็นหัวหน้า เหลือคนเดียว = ยุบ · กรอบสมาชิกซ้ายบน (HP/MP/แผนที่) คลิกชื่อ = เดินไปหา
  - **ขอเข้าร่วมปาร์ตี้** (ทิศตรงข้ามของการชวน): คนที่ยังไม่มีปาร์ตี้คลิกผู้เล่นอื่น → **🙋 ขอเข้าร่วมปาร์ตี้** หรือเปิดหน้าต่างผู้เล่นออนไลน์ (P) แล้วกดดูอุปกรณ์ → ปุ่มเดียวกัน คำขอส่งตรงถึง**หัวหน้าปาร์ตี้**เสมอไม่ว่าจะคลิกสมาชิกคนไหน (หรือกลายเป็นคำเชิญตั้งปาร์ตี้ใหม่ถ้าคนนั้นยังไม่มีปาร์ตี้) หัวหน้าเห็นป๊อปอัปเดียวกับคำเชิญ กด **อนุมัติ/ปฏิเสธ** เช็คเลเวลห่างกันไม่เกิน ±10 และปาร์ตี้ไม่เต็มเหมือนการชวนทุกอย่าง
- **ติดตามหัวหน้าปาร์ตี้** (ปุ่ม 🚶 ติดตามหัวหน้า ในกรอบปาร์ตี้ · สมาชิกที่ไม่ใช่หัวหน้า · `public/js/follow.js`): เดินตามหัวหน้าอัตโนมัติ (ยืนรอบตัวหัวหน้าคนละมุม) · ตีมอนตัวเดียวกับที่หัวหน้ากำลังตี และสู้กลับมอนที่ตีเราหรือเพื่อนในปาร์ตี้ (ไม่ไปตีมอนของคนอื่น ไม่ห่างหัวหน้าเกิน 650) · ใช้สกิลที่ติ๊กและยาตามที่ตั้งใน **กล่องบอท (O)** · หัวหน้าเปลี่ยนแผนที่ (ประตู / ศิลา / GM) = สมาชิกที่ติดตามและอยู่ใกล้ วาร์ปตามไปด้วย (สนามรบ PvP เฉพาะฝ่ายเดียวกัน) · กด WASD / จอย / คลิกพื้น = ควบคุมเองชั่วคราวแล้วตามต่อ · หยุดเมื่อกดป้ายสีฟ้าเหนือแถบสกิล, ออก/ยุบปาร์ตี้, ได้เป็นหัวหน้า, เปิดบอท หรือเดินทางด้วยแผนที่ใหญ่ · คนในปาร์ตี้เห็น 🚶 หน้าชื่อคนที่กำลังติดตาม (เซิร์ฟเวอร์: `partyFollow`, ตำแหน่ง/เป้าหมายของหัวหน้าใน `sendParty`, `changeMap` พาผู้ติดตามไป)
- **กติกาแบ่งของปาร์ตี้ (แบบ Ragnarok)**: หัวหน้าคลิกปุ่มในกรอบปาร์ตี้เพื่อสลับ (สมาชิกเห็นค่าปัจจุบัน · ป๊อปอัปคำเชิญบอกกติกาด้วย · เปลี่ยนแล้วแจ้งในแชทปาร์ตี้) — ค่าเริ่มต้น EXP แบ่งเท่ากัน · ไอเทมแบ่งในปาร์ตี้ (`C.PARTY_EXP_MODES` / `C.PARTY_ITEM_MODES` / `C.PARTY_DEFAULT` ใน `shared/common.js`, `partySetRules` / `shareExp` / `rollLoot` ใน `server/world.js`)
  - **EXP แบ่งเท่ากัน**: แบบเดิมด้านล่าง · **EXP ต่างคนต่างได้**: สมาชิกที่อยู่ใกล้และตีมอนตัวนั้นได้ EXP ตามสัดส่วนดาเมจ ไม่มีโบนัสปาร์ตี้
  - **ไอเทมแบ่งในปาร์ตี้**: ทองหารเท่ากันให้สมาชิกที่อยู่ใกล้ (แต่ละคนได้โบนัสทองของตัวเอง) · ไอเทมสุ่มให้สมาชิกที่อยู่ใกล้ 1 คน (กระเป๋าเต็มส่งต่อคนถัดไป) แจ้งในแชทปาร์ตี้ว่าใครได้ · **ไอเทมต่างคนต่างเก็บ**: ทองและไอเทมเป็นของคนที่ปราบ
  - "อยู่ใกล้" = ยังไม่ตาย แผนที่เดียวกัน ห่างจากมอนไม่เกิน `PARTY_RANGE` · ในสนามรบ PvP นับเฉพาะฝ่ายเดียวกับคนที่ปราบ · บอสยังแบ่ง EXP/ทองตามดาเมจเหมือนเดิม
- **แบ่ง EXP ปาร์ตี้**: สมาชิกที่ยังไม่ตาย อยู่แผนที่เดียวกันและห่างจากมอนสเตอร์ไม่เกิน `PARTY_RANGE` (1400) รวม EXP เป็นกอง **2 คน +25% แล้วเพิ่มคนละ +2%** (`PARTY_BONUS` / `PARTY_BONUS_STEP` · 2 คน +25% · 3 คน +27% · 4 คน +29% · 8 คน +37%) แล้วแบ่งตามสัดส่วนเลเวล · **เข้าปาร์ตี้ได้เฉพาะเลเวลห่างจากทุกคนในปาร์ตี้ไม่เกิน ±10** (`PARTY_LVL_GAP` ตรวจตอนชวนและตอนกดตอบรับ) · แถบบัพใต้กรอบตัวละครขึ้นป้าย **EXP +N%** เมื่อมีสมาชิกอยู่ใกล้ · บอสยังแบ่งตามดาเมจเหมือนเดิม
- **อัตรา EXP แบบโยวกัง**: EXP มอนสเตอร์ × `EXP_RATE / (1 + เลเวลมอนสเตอร์/8)` (`shared/common.js`) ยิ่งเลเวลสูงยิ่งได้น้อยลง และ EXP ที่ต้องใช้ต่อเลเวลคูณ `EXP_CURVE` ที่ชันขึ้นตามเลเวล (ขั้นบันไดเพิ่มที่ Lv.60 และ Lv.100): แล้วคูณ **ตัวคูณตามเลเวลผู้เล่น** `C.levelExpMul` (`EXP_LEVEL`): ×3 ถึง Lv.10 → ลดลงจนเป็น ×1 ที่ Lv.50 · ×1 ถึง Lv.80 → ลดลงจนเหลือ ×0.7 ที่ Lv.129 (ช่วงต้นขึ้นเร็ว ช่วงท้ายช้าลง · ใช้กับ EXP มอนและบอส) · ล่ามอนเลเวลใกล้ตัวคนเดียว (6 วิ/ตัว) เวลารวมถึง Lv.11 ≈ 0.1 ชม. · Lv.31 ≈ 1.4 ชม. · Lv.51 ≈ 9 ชม. · Lv.71 ≈ 33 ชม. · Lv.101 ≈ 117 ชม. · Lv.130 ≈ 295 ชม. (ปาร์ตี้และบอทเร็วกว่ามาก) · ปรับเร็วขึ้นทั้งเซิร์ฟด้วย `EXP_RATE` (เช่น 2 = x2) · มอนสเตอร์ต่ำกว่าเลเวลเรา 4–6 = EXP 60% · 7–10 = 20% · เกิน 10 = 5%
- สนามรบธรรมะ-อธรรม: ฐานฝ่ายตัวเองห้าม PvP ฟื้นพลังเร็ว · ฐานศัตรูลดพลัง 8%/วินาที · นอกฐานสังหารศัตรูได้ +1 คะแนนฝ่าย ปราบ "ราชันมารโลหิต" กลางแผนที่ได้ +10
- **อันดับผู้เล่น** (ปุ่ม **R** / 🏆 · `public/js/rank.js`, `World.onRank` / `buildRank`): 3 แท็บ **เลเวล** (เลเวล แล้ว EXP) · **สังหาร PvP** · **ฝ่าย** (คะแนนสนามรบตอนนี้ จำนวนตัวละคร คิล PvP รวม จำนวน Lv.100+ และอันดับ 1 ของแต่ละฝ่าย) แสดง Top 50 (`RANK_TOP`) และอันดับของตัวเองด้านล่างเสมอ
  - คำนวณจากตัวละครที่บันทึกทั้งหมด (ตัวที่ออนไลน์ใช้ค่าปัจจุบัน) สร้างใหม่อย่างมากนาทีละครั้ง (`RANK_MS`) · บัญชี GM ขึ้นอันดับเหมือนผู้เล่นทั่วไป (ไม่ให้ใครรู้ว่าเป็น GM)
  - **คิล PvP ที่นับในอันดับ** (`pvp` ในเซฟ แยกจาก `kills` เดิม): ผู้ถูกฆ่าต้องเลเวลต่ำกว่าผู้ฆ่าไม่เกิน 20 (`RANK_LVL_GAP`) และฆ่าคนเดิมนับได้ 1 ครั้งทุก 10 นาที (`RANK_REPEAT_MS`) กันการฟาร์มตัวรอง
  - คะแนนสนามรบยังอยู่ในหน่วยความจำ เริ่มนับใหม่เมื่อรีสตาร์ทเซิร์ฟเวอร์
- เลเวลสูงสุด 130 สกิลปลดล็อกตามเลเวล · ตัวละครในโลกเกมย่อขนาดลง (`PLAYER_SCALE` 0.38 ใน `main.js`; วงแหวน/ออร่าย่อตาม)
- ไอเทม Lv.100 (ระดับสูงสุด) ดรอประดับ Epic+ ได้จากมอนสเตอร์ Lv.100 ขึ้นไปทุกตัว (`TOP_ITEM_LVL`)

## คำสั่ง GM สำหรับทดสอบ

**ต้องปลดล็อกก่อนทุกครั้งที่เข้าเกม**: พิมพ์ `/gmcode <รหัส>` ในแชท (รหัสอยู่ใน `GM_CODE` ใน `.env` · ไม่ตั้ง = ใช้คำสั่ง GM ไม่ได้) · ปิดด้วย `/out <รหัส>` หรือออกจากเกม · รหัสผิด / ยังไม่ปลดล็อก / ไม่ใช่บัญชี GM จะขึ้นแค่ "ไม่รู้จักคำสั่งนี้" เหมือนพิมพ์คำสั่งที่ไม่มีอยู่ · ใส่รหัสผิด 5 ครั้ง `/gmcode` ใช้ไม่ได้ 10 นาที · สถานะ GM ไม่แสดงให้ผู้เล่นอื่นเห็น (ขึ้นอันดับตามปกติ ผู้รับของเห็นแค่ "ได้รับของรางวัล")

ใช้ได้เฉพาะบัญชีที่เป็น GM (`npm run gm -- <บัญชี>`) · ตั้ง `GM=all` = ทุกคนใช้ได้ (ทดสอบในเครื่องเท่านั้น) · `GM=0` = ปิด · พิมพ์ **`/gm`** ในช่องแชทเพื่อเปิดหน้าต่าง GM (ไม่มีปุ่มบนหน้าจอ · คำสั่งและผลลัพธ์ GM จะไม่แสดงในช่องแชท) หรือพิมพ์คำสั่งในแชทได้เลย:

| คำสั่ง | ผล |
|---|---|
| `/item w10` · `/item sh7` · `/item 110` · `/item มังกรทอง` | เสกไอเทม (รหัส w0–w13 / sh1–sh13 / pa1–pa13 / br1–br13 / sd1–sd13, เลเวลอาวุธ หรือบางส่วนของชื่อ) ตามจำนวน |
| `/item w10 1 mythic` · `/item sh5 3 epic` · `/item w7 1 4` | เสกไอเทมตามระดับ (0–5 หรือ normal / rare / epic / unique / legendary / mythic) แต่ละชิ้นสุ่มออฟชั่นใหม่ |
| `/set 9` · `/set 50 mythic` · `/set tier:10` | เสกชุดเกราะครบ 4 ชิ้น ใช้เลเวล 10–130 ทุก 10 เลเวล หรือรหัสชุด `tier:1`–`tier:13` (เลข 1–9 แบบเดิมยังใช้ได้) ระบุระดับไอเทมต่อท้ายได้ |
| `/item all` | เสกอาวุธครบทุกระดับ |
| `/lv 130` | ตั้งเลเวล 1–130 (ถ้าลดเลเวลจนสวมอาวุธไม่ได้ อาวุธจะกลับเข้ากระเป๋า) |
| `/exp +10` · `/exp 1000` | เพิ่ม EXP 10 หรือ 1,000 หน่วยให้ตัว GM เอง ใช้จำนวนเต็มบวกไม่เกิน 1,000,000,000; เลื่อนเลเวลและรับแต้มตามระบบปกติ ไม่คูณโบนัส EXP และไม่รองรับ `@ชื่อ` |
| `/map fire` · `/map 3` · `/map pvp` | วาร์ปไปแผนที่ (รหัส village / pass / forest / manor / temple / ice / fire / pvp, ลำดับ 1–8 หรือบางส่วนของชื่อ) ไม่เช็คเลเวล |
| `/goto 110 20` | ย้ายไปช่อง (tx, ty) ในแผนที่ปัจจุบัน |

## ระบบไอเทม

- อาวุธดาบคู่ 10 ระดับ (Lv.10–100) + ดาบฝึกหัดเริ่มต้น เพิ่มพลังโจมตีและคริติคอล ต้องมีเลเวลถึงจึงสวมได้ แต่ละระดับมีรูปทรงใบดาบของตัวเอง (ตรง → โค้ง → ใบไม้ → ตะขอ → ใบกว้าง → สายฟ้า → คดกริช → คลื่นน้ำ → เปลวไฟ → ใบเทพมีหนาม) ยาวขึ้นตามเลเวล และมีลวดลายเพิ่มตามระดับ (อักขระเรืองแสง อัญมณี ช่องวิญญาณ เกล็ดมังกร ดาว)
- **กระเป๋า 60 ช่อง** (`C.BAG_SIZE` · เลื่อนดูได้) แสดงจำนวนที่ใช้ · **⇅ จัดเรียง**: อาวุธ → เสื้อ → กางเกง → ปลอกแขน → หัวไหล่ แล้วเลเวล ระดับ และ + สูงก่อน (`C.sortBag`) · **☑ จัดอัตโนมัติ** (จำไว้ในเซฟ): จัดเรียงทุกครั้งที่กระเป๋าเปลี่ยน · คำสั่งที่อ้างช่องกระเป๋า (สวม ขาย ทิ้ง ตีบวก ฝาก) ส่งรหัสไอเทมไปด้วย ถ้ากระเป๋าเพิ่งถูกจัดใหม่ เซิร์ฟเวอร์ปฏิเสธแทนการทำกับไอเทมผิดชิ้น (`bagKeyOk`)
- **คลังเก็บของ** (📦 ในกระเป๋า หรือปุ่มในหน้าต่างศิลา · ใช้ได้ที่ช่างตีดาบ/ศิลาเคลื่อนย้ายในค่ายพักทุกแผนที่ · `public/js/storage.js`, `onStorage`): ของแต่ละตัวละคร 120 ช่อง (`C.STORAGE_SIZE`) + ฝาก/ถอนทอง · ขณะเปิดคลัง ดับเบิลคลิก/คลิกขวาไอเทมในกระเป๋า = ฝาก · ในคลัง = นำออก · ติ๊กหลายชิ้นแล้วกด **ฝาก N ชิ้น** · ⇅ จัดเรียงคลัง · เดินออกจากค่ายคลังปิดเอง
- **เลือกหลายชิ้นในกระเป๋า**: ติ๊กช่อง ☐ ที่มุมไอเทม แถบด้านบนบอกจำนวนและราคาขายรวม · ปุ่ม เลือกทั้งหมด / ยกเลิก / **ขาย N ชิ้น** (ต้องเปิดร้านช่างตีดาบ) / **ทิ้ง N ชิ้น** · ถามยืนยันก่อนเสมอและบอกชื่อไอเทมระดับ Epic ขึ้นไปที่อยู่ในรายการ (เซิร์ฟเวอร์: `sellMany` ใน `onShop`, `onDiscard` รับรายการช่อง)
- ได้จากมอนสเตอร์ (ดรอปทอง + มีโอกาสดรอปอาวุธ, บอสดรอปแน่นอน 1 ชิ้นให้ผู้ทำดาเมจสูงสุด) หรือซื้อที่ร้านช่างตีดาบ
- อาวุธที่สวมเปลี่ยนการแสดงผลจริง: ตัวละครถือดาบตามดีไซน์ของไอเทมนั้น (ภาพเวกเตอร์ คมชัดทุกขนาด) ทั้งท่าเดิน/โจมตี ดาบระดับสูงยาวและอลังการขึ้น, แสงเรืองที่ใบดาบ, ประกายจากใบดาบ (ประกายไฟ → สายฟ้า → วิญญาณวน → เปลวมังกร), วงแสงใต้เท้า (Lv.70+) — ไม่มีแสงทับตัวละคร และสีแสงฟันของสกิล ผู้เล่นคนอื่นเห็นเหมือนกัน
- ฝ่ายธรรมะเป็นโทนฟ้า/ทอง/น้ำเงิน (ดาบ Lv.90–100 เรืองแสงน้ำเงินเข้ม) ฝ่ายอธรรมเป็นโทนแดง/ทอง
- **ระดับไอเทม (Grade) = เส้นแสงตัดขอบตัวละคร** สีตามฝ่าย ยิ่งระดับสูงเส้นยิ่งเข้ม (ดูตารางในหัวข้อชุดเกราะ) · ไม่มีแสงทับตัว ไม่มีประกาย ไม่มีวงแสงหมุนรอบตัว
- เอฟเฟกต์อลังการขึ้นตามขั้นเอฟเฟกต์ (`WeaponLook.power`, ค่าสูงกว่าระหว่างระดับอาวุธกับขั้นวิชา × 0.8):
  - Lv.30+ แสงฟันชั้นนอก · Lv.40+ น้ำวนใต้เท้าตอนหมุนดาบ · Lv.50+ ภาพติดตาของแสงฟัน วงเวทใน ult · Lv.60+ สายฟ้าตามดาบ/จุดปะทะ คลื่นกระแทก
  - Lv.70+ วงเวทรูนใต้เท้า (นิ่ง ไม่หมุน) เสาแสงตอนสวมอาวุธ · Lv.80+ รอยไหม้ตามเส้นทางพุ่ง · Lv.90 วงเวทซ้อน + ฟันกากบาทเป็นดาว 8 แฉก
  - Lv.100 ดาบสวรรค์ยักษ์ปักลงกลางพันดาบพิฆาต
  - จุดปะทะ (ตัวเลขดาเมจ) ใช้สีและความแรงตามอาวุธของผู้โจมตี
- ตารางดรอปและค่าสถานะอยู่ใน `shared/common.js` (`WEAPONS`, `ARMOR_SETS`, `ARMOR_STATS`, `GRADES`, `GRADE_LIGHT`, `AFFIXES`, `OPTIONS`, `PASSIVES`) และ `shared/world-data.js` (ดรอปของมอนสเตอร์)

ไอเทมทุกเลเวลมี 6 ระดับ ระดับสุ่มตอนดรอป (ไอเทมชิ้นเดียวกันอาจได้คนละระดับ) ร้านช่างตีดาบขายได้ถึงระดับ **Unique** (Normal ถึง Unique เลือกกดซื้อแยกราคาต่อระดับในแต่ละแถว) Legendary/Mythic ดรอปเท่านั้น

### ตีบวกอาวุธและชุดสวมใส่ 4 ชิ้น (+1 ถึง +10)

ที่ร้านช่างตีดาบ แท็บ **⚒ ตีบวก** เลือกอาวุธ / เสื้อ / กางเกง / ปลอกแขน / หัวไหล่ ที่สวมอยู่หรือในกระเป๋า
ทุกครั้งใช้ **หินตีบวก** (ซื้อ 120 · ขายคืน 60 ทอง/ก้อน ที่แท็บเดียวกัน ปุ่มซื้อ ×1/×10/×50 ขาย ×1/×10) + ค่าช่างเล็กน้อย
จำนวนหินต่อครั้ง = (1,1,1,2,2,3,3,4,5,6 ตามขั้น) × (1 + เลเวลไอเทม ÷ 20) · จำนวนหินที่มีแสดงในกระเป๋าและร้าน

| ไป | โอกาสสำเร็จ | ล้มเหลว | เอฟเฟกต์ที่อาวุธ |
|---|---|---|---|
| +1 / +2 / +3 | 95% / 90% / 80% | **สุ่ม 3 ทาง** (ลดจาก +1 = แตกหาย) | แสงขาว → ฟ้าอ่อน → ฟ้าคราม |
| +4 / +5 | 70% / 60% | **สุ่ม 3 ทาง** | แสงหยกเต้นเป็นจังหวะ / แสงทอง + ประกายไฟฟ้า |
| +6 | 45% | **สุ่ม 3 ทาง** | แสงถ่านไฟ + ประกายไฟฟ้าวิ่งบนใบดาบ |
| +7 / +8 | 35% / 25% | **ไอเทมแตกหาย** | สายฟ้าน้ำเงิน / ม่วง วิ่งบนใบดาบและกระโดดระหว่างดาบสองเล่ม |
| +9 | 8% | **ไอเทมแตกหาย** | พายุสายฟ้าแดง + สายฟ้าฟาดพื้นรอบตัว |
| +10 | 3% | **ไอเทมแตกหาย** | แสงสายรุ้งเปลี่ยนสี สายฟ้าทองตลอดเวลา ฟาดพื้นถี่ขึ้น |

- **+1 ถึง +6 (ล้มเหลวแล้วสุ่ม 3 ทาง, ไม่มียันต์กันแตก):** ก่อนอื่นสุ่มว่าแตกสลายทันทีไหม — โอกาส 30% (`C.ENHANCE.softBreakChance`) ถ้าไม่แตก (70%) จะเป็น "ล้มเหลวแบบนิ่ม" ซึ่งสุ่มต่ออีก 50/50 (`C.ENHANCE.softDemoteChance`) ระหว่าง **ระดับคงเดิม** กับ **ลดระดับลง 1** · ถ้าลดจาก +1 แล้วจะเหลือ +0 ระบบจะแตกสลายไอเทมทิ้งแทน (ไม่มี +0 ที่เคยตีบวกมา) — รวมแล้วโอกาสที่ไอเทม **ไม่แตก** (คงเดิมหรือลดระดับ) สูงกว่าโอกาสแตกเสมอ
- **+0 และ +7 ถึง +10:** ล้มเหลวแล้ว**ไอเทมแตกสลายทันที** เหมือนเดิม ทุกเกรดตั้งแต่ Normal ถึง Mythic (มีกล่องยืนยันก่อนกดทุกครั้ง) · โอกาสหาย = 100% − โอกาสสำเร็จ · อาวุธที่สวมอยู่แตก = กลับไปถือดาบฝึกหัด
- ยันต์กันแตก (ยันต์กันแตก/ขั้นกลาง/ขั้นสูง) ยังป้องกันแตกได้ 100% ทุกขั้น (ระดับคงเดิมเสมอ ไม่สุ่มเลย) ขั้นที่เริ่มสุ่ม/แตกตั้งได้ที่ `C.ENHANCE.softPlusMin` / `softPlusMax` / `softBreakChance` / `softDemoteChance`
- **ดาเมจใส่มอนสเตอร์** มาจาก**การตีบวกทั้งชุด** (อาวุธ +10 = +75% · ชุดแต่ละชิ้น +10 = +18.75% · ครบ 5 ชิ้น +10 = ×2.5) × **โบนัสชุดครบ 5 ชิ้น** ตามระดับต่ำสุดของชุด (Rare +3% · Epic +6% · Unique +10% · Legendary +15% · Mythic +20%) — ระดับ/เลเวลอาวุธไม่เพิ่มดาเมจมอนแล้ว (ไม่มีผลใน PvP · `C.gearPve`) แสดงในหน้าต่างค่าสถานะ ทูลทิปไอเทม และแถวตีบวก
- อาวุธ: พลังโจมตีเพิ่มทุกระดับ คริติคอลเพิ่มตั้งแต่ +6 · ชุด: ป้องกัน / พลังชีวิต / ปราณ / พลังโจมตี (ปลอกแขน) เพิ่มตามค่าของชิ้นนั้น
- อาวุธ +5 ขึ้นไปฟันแล้วมีสายฟ้าสีตามระดับบวก · ตีบวก +8 ขึ้นไปสำเร็จ หรือ +7 ขึ้นไปแตก จะประกาศให้ทุกคนเห็น

ปุ่ม "สุ่มออฟชั่นใหม่" / "สุ่มสกิลติดตัวใหม่" อยู่ในแถวตีบวกของแต่ละไอเทม (แท็บ ⚒ ตีบวก) ขึ้นเฉพาะไอเทมที่มีส่วนนั้นให้สุ่ม ใช้หินของขั้นเดียวกับที่ตีบวกไอเทมชิ้นนั้น · ของเดิมหายไปถาวรเมื่อสุ่มใหม่ (มีกล่องยืนยันก่อนกด) · กลไก: `shared/common.js` เก็บ seed แยก (`aSeed`/`pSeed`) สำหรับส่วนออฟชั่นกับส่วนสกิลติดตัว ทำให้สุ่มใหม่ได้ทีละส่วนโดยไม่กระทบส่วนอื่นของไอเทม

ซื้อ/ขายได้ทั้งปุ่มลัด (×1/×5/×10…) และ**ช่องใส่จำนวน** (ปุ่ม "สูงสุด" = มากที่สุดที่ทองพอ · แสดงราคารวม · Enter = ซื้อ) · **วัสดุผิดขั้นตีบวกไม่ได้:** ติ๊กยันต์ไว้แต่ไม่มียันต์ขั้นของไอเทมนั้น ปุ่มตีบวกถูกปิดพร้อมบอกว่าต้องใช้ขั้นไหน และเซิร์ฟเวอร์ปฏิเสธคำขอที่ใช้วัสดุขั้นอื่นโดยไม่หักอะไรเลย · ขายคืนได้ 25% ของราคาซื้อ (หินขั้นต้น 50%) · แท็บ ✦ วัสดุตีบวก แสดงครบทุกขั้น · แท็บ ⚒ ตีบวก แสดงเฉพาะขั้นที่ไอเทมของผู้เล่นต้องใช้ · จำนวนวัสดุในกระเป๋า/ร้านแสดงเป็น "ขั้นต้น · ขั้นกลาง · ขั้นสูง"

- ติ๊ก "ใช้ยันต์ทุกครั้งที่ตีบวก" ในแท็บตีบวก แล้วยันต์จะถูกใช้ครั้งละ 1 ใบต่อการตีบวก 1 ครั้ง **หมดไปแม้ตีบวกสำเร็จ** ใช้ทั้งสองแบบพร้อมกันได้
- ถ้าติ๊กยันต์กันแตกไว้ จะไม่มีกล่องยืนยันความเสี่ยง · การซื้อยันต์มีกล่องยืนยันราคาทุกครั้ง
- ยันต์และหินขั้นกลาง/สูงเก็บเป็นจำนวน (`charms` ในเซฟ: `guard` `luck` `stone2` `guard2` `luck2` `stone3` `guard3` `luck3`) ไม่กินช่องกระเป๋า ราคาและผลตั้งที่ `C.ENH_CHARMS` · ทดสอบ `node tools/check-enhance-tiers.cjs`

### ขายอัตโนมัติเมื่อดรอป

ในกระเป๋า (I) แถว **ขายอัตโนมัติเมื่อดรอป** กดเลือกเกรดได้หลายเกรด (Normal · Rare · Epic · Unique · Legendary · Mythic)
ไอเทมที่ดรอปในเกรดที่เลือกจะขายเป็นทองทันทีในราคาขายร้าน (ไม่เข้ากระเป๋า ใช้ได้ทุกที่และแม้กระเป๋าเต็ม)
เลือกเกรด Epic ขึ้นไปมีกล่องยืนยัน · ค่าที่เลือกบันทึกกับตัวละคร (`autoSell`)
- รหัสไอเทมเก็บเป็น `w5+3` / `sh5+3` · GM: `/plus 10` ตั้งระดับบวกของอาวุธที่สวม · `/plus 10 armor` ชุดทั้ง 4 ชิ้น (`body` / `legs` / `arms` / `shoulder` / `all`) · `/item w10+10` เสกอาวุธบวก · `/stone 500` เพิ่มหินตีบวก
