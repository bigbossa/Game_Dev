# ธรรมะ ⚔ อธรรม Online

เกม 2D MMORPG บนเบราว์เซอร์ แนวยุทธภพจีน (Yulgang / Ragnarok) สองฝ่าย **ธรรมะ** (โทนขาว-ฟ้า-ทอง) และ **อธรรม** (โทนดำ-แดง)
เซิร์ฟเวอร์เป็นตัวตัดสินทุกอย่าง (authoritative) ฝั่งผู้เล่นวาดภาพด้วย Canvas

- Node.js + Express + Socket.IO · ฐานข้อมูล PostgreSQL (หรือ Supabase)
- 6 อาชีพ · เลเวล 1–130 · 7 แผนที่ล่ามอนสเตอร์ + สนามรบ PvP
- แผนที่ล่ามอนใช้ร่วมกันทั้งสองฝ่าย ฝ่ายมีผลเต็มที่ในสนามรบธรรมะ-อธรรม

---

## เริ่มใช้งาน

### รันในเครื่อง

ต้องใช้ Node.js **20.12 ขึ้นไป** (เซิร์ฟเวอร์อ่าน `.env` ด้วย `process.loadEnvFile`) และ PostgreSQL

```bash
npm install
copy .env.example .env      # แล้วใส่ DATABASE_URL
npm start                   # http://localhost:3900
npm run dev                 # รันแบบรีสตาร์ตเองเมื่อแก้โค้ด
```

### รันด้วย Docker (ใช้กับเซิร์ฟเวอร์จริง)

```bash
docker compose up -d --build   # http://localhost:3900
```

- มีสองบริการ: `db` (postgres:16-alpine) และ `game` (node:24-alpine)
- image รวมเฉพาะ `server/` `shared/` `public/` ไฟล์ภาพต้นฉบับและเครื่องมือไม่ถูกใส่ (ดู `.dockerignore`)
- **แก้โค้ดแล้วต้อง `docker compose up -d --build` ใหม่ทุกครั้ง** เกมจะรีสตาร์ต ผู้เล่นที่ออนไลน์หลุดชั่วครู่ แล้วผู้เล่นรีเฟรชหน้าเว็บหนึ่งครั้ง

### ค่าใน `.env`

| ค่า | ใช้ทำอะไร |
|---|---|
| `DATABASE_URL` | ฐานข้อมูล PostgreSQL (สร้างตารางให้เองตอนเปิดครั้งแรก) |
| `SUPABASE_DB_URL` | ถ้าตั้งไว้จะใช้ฐานข้อมูลบน Supabase แทน `DATABASE_URL` (Docker ใช้ Session pooler เพราะใช้ IPv6 ไม่ได้) |
| `SUPABASE_URL` · `SUPABASE_PUBLISHABLE_KEY` · `SUPABASE_SECRET_KEY` · `SUPABASE_JWKS_URL` | เชื่อม Supabase API (ห้ามใส่ secret key ในโค้ดฝั่งเบราว์เซอร์) |
| `PORT` | พอร์ตเซิร์ฟเวอร์ (ค่าเริ่มต้น 3900) |
| `GM` | ไม่ใส่ = เฉพาะบัญชี GM · `all` = ทุกคนใช้คำสั่ง GM ได้ · `0` = ปิด |
| `GM_CODE` | รหัสปลดล็อกคำสั่ง GM ในเกม (`/gmcode <รหัส>`) ไม่ตั้ง = ใช้คำสั่ง GM ไม่ได้ |
| `MAX_CHARS` | จำนวนตัวละครต่อบัญชี (ค่าเริ่มต้น 6) |

> ⚠ **ก่อนเปิดให้คนอื่นเล่นจริง อย่าใช้ `GM=all`** เพราะทุกคนจะเสกไอเทม ทอง และเลเวลได้

### บัญชีและการบันทึก

- หน้าแรก: เข้าสู่ระบบ / สมัครบัญชี → เลือกตัวละคร → สร้างตัวละครใหม่ (เลือกฝ่าย อาชีพ ชื่อ) · ช่องรหัสผ่านมีปุ่มแสดงรหัส · รีเฟรชแล้วไม่ต้องล็อกอินใหม่ (โทเคน 30 วัน)
- เปลี่ยนรหัสผ่านได้ในหน้าเลือกตัวละคร (อุปกรณ์อื่นจะถูกออกจากระบบ) · ในเกมมีปุ่มสลับตัวละครโดยไม่ต้องล็อกอินใหม่
- ตาราง: `accounts` (รหัสผ่านแบบ scrypt · `is_gm`) · `sessions` (เก็บเฉพาะ sha256 ของโทเคน) · `characters` (เซฟทั้งก้อนใน `data` JSONB) · `meta`
- ตัวละครอยู่ในหน่วยความจำ เขียนลงฐานข้อมูลทุก 20 วินาที ตอนผู้เล่นออก และตอนปิดเซิร์ฟเวอร์ (`server/store.js`)
- ตัวละครเก่าจาก `data/players.json` ถูกนำเข้าครั้งเดียว ผูกเข้าบัญชีได้ในหน้าเลือกตัวละคร (ใครผูกก่อนได้ก่อน)

- **นักรบแนวหน้า:** สกิลยั่วยุ "คำรามท้าศึก" (คูลดาวน์ 6 วินาที ดึงมอนทุกตัวรอบตัวระยะ 300/340/380 ตามขั้น) มอนตีเราต่อหลังหมดผล ไม่ให้ EXP หรือดาเมจปลอม · พาสซีฟ "โล่หนาม" สะท้อนดาเมจ 8% (25% ตอนตั้งโล่เหล็ก · PvP ครึ่งเดียว) · พาสซีฟ "โล่รับแทน" เพื่อนในปาร์ตี้ระยะ 300 โดนตี นักรบรับแทน 30% (PvP 15% · บัพโล่ของนักรบลดส่วนที่รับ · หยุดรับแทนเมื่อ HP นักรบต่ำกว่า 30%) · ท่าไม้ตาย 0 / - "โล่พิทักษ์ทลายแนว" 700% และ "ป้อมปราการถล่มฟ้า" 1100% · "สัตย์พิทักษ์" และ "ดาบมหาปราการ" ย้ายเป็นสกิลเสริม (ไม่มีปุ่มประจำ ตั้งปุ่มเองในคัมภีร์วิชา)
- เอฟเฟกต์สกิลอลังการขึ้นตามแต้มสกิล ขั้นวิวัฒนาการ และเลเวล ดู [docs/skill-redesign.md](docs/skill-redesign.md) · [docs/skill-performance.md](docs/skill-performance.md)

### รูปลักษณ์ตามเลเวล

อาชีพเดิมเปลี่ยนรูปลักษณ์ตาม `ModelTiers.LEVELS` ส่วนเทวทัณฑ์ใช้ขั้น Lv.30/70/110 และร่างจุติชั่วคราว ผู้เล่นคนอื่นเห็นผ่าน snapshot เดียวกัน

| เลเวล | สิ่งที่เปลี่ยน |
|---|---|
| 15 | สีผมเปลี่ยน |
| 30 | ผมยาวขึ้น (ทรงผมยาวของอาชีพ) |
| 50 | สีผมขั้นสูง + มงกุฎ / พู่หมวก |
| 60 | ปีกคู่แรก |
| 80 | ปีกใหญ่ขอบทอง |
| 100 | ปีกสองคู่ + รัศมี (ธรรมะ) / เขาเทพมาร (อธรรม) + ออร่าอาชีพ |
| 130 | ร่างสุดท้าย: เทพเซียน (จานสุริยะ ปีกสามคู่) / เทพมาร (เปลวมาร ปีกพังผืด) |

ชุดเกราะบนตัวละครเปลี่ยนสีและลายตามชุดที่สวมจริงทีละชิ้น อาวุธในมือเปลี่ยนตามขั้นอาวุธ เกรดไอเทมเป็นเส้นแสงขอบตัวและออร่า ค่าตีบวกเป็นแสงและสายฟ้าบนอาวุธ ดู [docs/class-aura.md](docs/class-aura.md) · [docs/equipment-aura.md](docs/equipment-aura.md)

- ข้อมูลแผนที่ มอนสเตอร์ และดรอปอยู่ใน `shared/world-data.js` · หมู่บ้านเป็นแผนที่วาดมือ (`shared/village-map.js`, [docs/village-v2-design.md](docs/village-v2-design.md))
- มอนสเตอร์อยู่เป็นฝูง ตีตัวหนึ่งตัวอื่นในฝูงที่อยู่ใกล้จะเข้ามาช่วย · **มอนสเตอร์ไม่ตีผู้เล่นก่อน** จนกว่าจะถูกตีหรือถูกยั่วยุ
- ทุกแผนที่มี **ค่ายพัก** (เขตปลอดภัย ฟื้นพลังเร็ว) มีร้านช่างตีดาบ ร้านขายยา ร้านตีบวก ศิลาเคลื่อนย้าย และคลังเก็บของ · ตายแล้วเกิดที่ค่ายพักของแผนที่นั้น
- **วาร์ปได้ทุกแผนที่ไม่จำกัดเลเวล** · ศิลาเคลื่อนย้ายคิดค่าวาร์ป = จำนวนแผนที่ที่ข้าม × (100 + 8 × เลเวลเริ่มของแผนที่ที่สูงกว่า) · เดินผ่านประตูแผนที่ฟรี
- มอนสเตอร์ Lv.1–80 อ่อนลงเพื่อให้ช่วงต้นเล่นง่าย · Lv.60+ อึดขึ้นตามอุปกรณ์ (ควรใส่ Epic หรือตีบวก) · ดู [docs/combat-balance.md](docs/combat-balance.md) และ `npm run gear-gate`
- **PvP นอกสนามรบ** (Lv.20+ กด U): ฆ่าผู้เล่นนอกสนามรบได้แต้มชั่วร้าย ชื่อแดง ฟื้นเองทุกชั่วโมง · ในสนามรบ ฐานฝ่ายตัวเองปลอดภัย ฆ่าศัตรูได้ +1 คะแนนฝ่าย

## EXP และเลเวล

- EXP ที่ต้องใช้ต่อเลเวลชันขึ้นตามเลเวล (ขั้นบันไดเพิ่มที่ Lv.60 และ Lv.100) · ตัวคูณ EXP ตามเลเวลผู้เล่น: ×3 ถึง Lv.10 → ×1 ที่ Lv.50–80 → ×0.7 ที่ Lv.129 (`C.levelExpMul`)
- มอนสเตอร์ Lv.100 ขึ้นไปให้ EXP เพิ่ม 30% (ค่อยๆ เพิ่มตั้งแต่ Lv.90 · `TOP_EXP` ใน `world-data.js`)
- **ตีมอนเลเวลสูงกว่า** ได้ EXP เพิ่ม 10% ต่อเลเวล (สูงสุด ×2) · **ตีมอนต่ำกว่า** 4–6 เลเวล = 60% · 7–10 = 20% · เกิน 10 = 5%
- ล่าคนเดียวมอนเลเวลใกล้ตัว (~6 วินาทีต่อตัว): Lv.30 ≈ 1 ชม. · Lv.60 ≈ 16 ชม. · Lv.100 ≈ 101 ชม. · Lv.130 ≈ 222 ชม. (ปาร์ตี้และบอทเร็วกว่ามาก) · หลอด EXP แสดงทศนิยม 2 ตำแหน่ง
- ปรับเร็ว/ช้าทั้งเซิร์ฟเวอร์ได้ที่ `EXP_RATE` ใน `shared/common.js` · ดู [docs/level-progression.md](docs/level-progression.md)

### แต้มสถานะและแต้มสกิล

- ได้แต้มสถานะ 3 แต้มต่อเลเวล (กด C) ลงได้ 6 ค่า: พลังโจมตี +1.5 · ป้องกัน +1 · พลังชีวิต +14 · ปราณ +7 · ตีเร็ว +1.5% (สูงสุด 80 แต้ม) · คริติคอล +0.4% (สูงสุด 75 แต้ม · คริติคอลรวมไม่เกิน 75%)
- มีปุ่มแจกตามแนวทางอาชีพ ระบบแจกอัตโนมัติ และรีเซ็ตแต้ม (Lv.30+ คิด เลเวล × 100 ทอง)
- แต้มสกิลเรียน/อัปสกิลในคัมภีร์วิชา (K)

## ไอเทม

- **อาวุธ** 14 ขั้น (Lv.1 ฝึกหัด, 10, 20 … 130) · **ชุดเกราะ** 13 ชุด (Lv.10–130 ทุก 10 เลเวล) ชุดละ 4 ชิ้น: เสื้อ (ป้องกัน/HP) · กางเกง (ความเร็ว) · ปลอกแขน (ATK/คริ) · หัวไหล่ (MP)
- **กระเป๋า 60 ช่อง** · **คลังเก็บของ 120 ช่อง** + ฝาก/ถอนทอง (ใช้ได้ในค่ายพัก)
- ยาและใบวาร์ปกลับเมืองซ้อนเป็นสเต็กได้สูงสุด 999 ต่อช่อง
- กระเป๋ามี: จัดเรียง · จัดอัตโนมัติ · เลือกหลายชิ้นเพื่อขาย/ทิ้ง · **⚡ สวมของดีสุด** (เน้น เลเวล/เกรด · พลังโจมตี · ป้องกัน · พลังชีวิต · คริ · ดาเมจคริ · EXP · ทอง · ดาเมจมอนสเตอร์) · **สวมของดีกว่าอัตโนมัติ** ทุกครั้งที่ได้อุปกรณ์หรือเลเวลอัป · **ขายอัตโนมัติเมื่อดรอป** ตามเกรดที่เลือก
- **🏮 ระดมทุน** (ปุ่ม 🏮 / G): ทุกคนร่วมลงทองในกระเป๋า (ขั้นต่ำ 1,000) ครบ **10,000,000** = ทั้งเซิร์ฟได้ **EXP ×2 · โอกาสดรอปไอเทม ×2** (บอสดรอป 2 ชิ้น) นาน 1 ชั่วโมง แล้วเริ่มรอบใหม่ · ทองที่เกินยกไปรอบถัดไป · ระดมครบระหว่างบัพ = ต่อเวลาอีก 1 ชั่วโมง · ร่วม 100,000 ขึ้นไปประกาศทั้งเซิร์ฟ · ค่าทั้งหมดอยู่ที่ `C.FUND` ([shared/common.js](shared/common.js)) · ยอดและเวลาบัพเก็บในตาราง `meta` (รีสตาร์ทไม่หาย)
- **แชท**: แท็บกรอง ทั้งหมด · ระบบ · ไอเทม · ฝ่าย · ปาร์ตี้ · ข้อความไอเทมเป็นสีตามเกรด · **Shift+คลิกไอเทม** (มือถือ: เมนูไอเทม → แชร์ในแชท) = แชร์ไอเทมให้คนอื่นชี้ดูค่าสถานะ (เซิร์ฟเวอร์ตรวจว่ามีของจริง) · ⚙ ตั้งระดับต่ำสุดของของที่ได้เองที่ขึ้นแชท · แสดงเวลา · เสียงประกาศ · ได้ Mythic หรือตีบวก +10 สำเร็จ = ประกาศกลางจอทุกคน
- รหัสไอเทม: `<id>#<เกรด>.<seed>~<aSeed>^<pSeed>+<บวก>` เช่น `w9#5.88+10` (Mythic +10) · ยาเก็บเป็น `<id>*<จำนวน>`

### ตีบวก (+1 ถึง +10)

ขั้นตอน: เลือกอาวุธหรือชุด (ที่สวมหรือในกระเป๋า) → ติ๊กยันต์ที่ต้องการ → กด **ตีบวก** ราคาบนปุ่มคือราคาที่จ่ายจริง

| ไป | โอกาสสำเร็จ | ถ้าล้มเหลว (ไม่มียันต์กันแตก) |
|---|---|---|
| +1 | 95% | แตกหาย |
| +2 – +6 | 90% / 80% / 70% / 60% / 45% | แตก 30% · ลดระดับ 35% · คงเดิม 35% |
| +7 – +10 | 35% / 25% / 8% / 3% | แตกหาย |

- **ค่าตีบวก (รวมหินแล้ว)** = ราคาพื้นฐานไอเทม × ตัวคูณตามขั้น (×0.6 ที่ +1 ถึง ×8 ที่ +10) ทุกเลเวลจ่ายเป็นสัดส่วนเท่ากัน ราคาไล่ต่อเนื่อง ไม่กระโดดตามขั้นวัสดุ
- **ยันต์กันแตก** (ล้มเหลวแล้วไม่แตก ระดับคงเดิม) = 30% ของมูลค่าที่เสี่ยงเสีย คือมูลค่าไอเทมรวมเกรดและบวกเดิม × โอกาสล้มเหลว (ขั้นต่ำ 20% ของค่าตีบวก)
- **ยันต์เพิ่มโอกาส** (+10% ถึง +8 · +4% ที่ +9 · +2% ที่ +10) = 40% ของค่าตีบวก
- หินหรือยันต์เก่าที่มีอยู่ (ขั้นเดียวกับไอเทม) ร้านใช้ก่อน หินลดค่าตีบวก 60% ตามสัดส่วนที่มี ยันต์ใช้แทนการจ่ายเงิน
- ราคาตัวอย่างต่อครั้ง (อาวุธ Normal ค่าตีบวก / ยันต์กันแตก): Lv.30 +10 ≈ 18k / 8k · Lv.100 +10 ≈ 960k / 431k · Lv.130 +10 ≈ 2.24M / 1.01M
- **สุ่มออฟชั่นใหม่** (Rare+) = ราคาพื้นฐาน × 0.8 · **สุ่มสกิลติดตัวใหม่** (Legendary+) = ราคาพื้นฐาน × 2 · ส่วนอื่นของไอเทมไม่เปลี่ยน
- ค่าตีบวกทั้งชุดเพิ่มดาเมจใส่มอนสเตอร์ (อาวุธ +10 = +75% · ชุดครบ 5 ชิ้น +10 = ×2.5) + โบนัสชุดครบ 5 ชิ้นตามเกรดต่ำสุด (ไม่มีผลใน PvP · `C.gearPve`)
- ตีบวก +8 ขึ้นไปสำเร็จ หรือ +7 ขึ้นไปแตก จะประกาศให้ทุกคนเห็น
- สูตรทั้งหมดอยู่ที่ `C.ENHANCE` ใน `shared/common.js` (`quote`, `cost`, `GUARD`, `LUCK`, `rerollPrice`)

เทสต์ภาพและเบราว์เซอร์ (`check-*-browser.cjs`, `check-skill-performance.cjs` ฯลฯ) ต้องเปิดเซิร์ฟเวอร์เกมและเบราว์เซอร์ที่เปิด remote debugging (CDP) ไว้ก่อน ระบุ URL และพอร์ตเป็นอาร์กิวเมนต์ · `node tools/preview-warrior.cjs` เปิดเซิร์ฟเวอร์พรีวิวภาพแบบอ่านอย่างเดียวที่พอร์ต 3902 · หน้าทดลองโมเดล `/studio.html` และ `/warrior-review.html`
